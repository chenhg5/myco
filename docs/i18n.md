# Interface languages

Settings → Appearance → Language, and the welcome screen, offer System default,
简体中文, 繁體中文, English, 日本語, 한국어, Español and Português (Brasil).
System default follows the first supported device language in preference order;
unsupported languages fall back to English. Chinese in Taiwan, Hong Kong and Macao
uses Traditional Chinese. Other Portuguese regions currently use Brazilian Portuguese.
Dates retain the device region in System mode. Manual language choices use that
language's default region. The choice is kept in the local App profile across upgrades.

Navigation, connecting a workspace, projects, conversations, agents, settings,
permissions, errors and native desktop menu/notification labels use offline catalogs.
Only the selected additional language pack is loaded from the installed App; changing
interface language sends no text to a translation service. A failed pack load keeps
the previous language (English on startup) and offers retry in the language picker.
Missing individual labels fall back to English. The full usage guide remains in
English for Japanese, Korean, Spanish and Portuguese.

Names, task bodies, agent replies, project documents and commands remain original.
The separate, optional message translation feature still requires the person's chosen
service and key; it targets the selected interface language and offers Show original.
Automatic detection checks scripts conservatively and does not guess between English,
Spanish and Portuguese; manual translation remains available. Voice calls retain their
existing Chinese/English model support; interface localization does not add speech
model capabilities. System dictation requests the selected language when supported.
Embedded applications manage their own translations; the host supplies its language
preference but does not rewrite an application's contents.

## Maintaining copy

Chinese and English authored copy remains next to the component: `L("设置", "Settings")`.
Additional catalogs live in `internal/uilocale/catalogs/` and are shared by web and
native desktop menus. Traditional Chinese uses Chinese source keys; other catalogs
use English source keys. Use complete sentence variants for plural/conditional copy.
For dynamic copy use `L(E\`发送给 ${name}\`, E\`Send to ${name}\`)` and import `E` from
`@/lib/i18n`. The tag makes numbered placeholders before inserting values; it never
searches user values or reinterprets them as markup. Preserve every placeholder,
printf conversion, URL, command and inline-code fragment in each translation.

Run `npm run test:i18n --prefix web` to check language matching, lazy loading,
persistence, failure recovery, extraction coverage and placeholder signatures.
`node web/scripts/i18n-catalog.mjs --manifest` lists source copy and dynamic expressions
for review. Review variable helper/table labels as well as direct `L` literals.
`npm run test:ui --prefix web -- --only 七种语言` verifies switching and core rendering
in both themes and widths. Rebuild and commit the generated web assets with `make web`.
