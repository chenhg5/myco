# 模板与套件：让网页成为人和 agent 一起用的工具（讨论稿）

> 状态：第一步、第二步已做（v0.20.5）：网页的记录和变化流、工作区里的模板库、`myco template` / `myco page data`、桥的 `myco.data.*` 和 `myco.download`；官方模板「表格」「多维表格」「文档」随 Hub 提供；App 边栏的「模板」。不做市场。

有了 App 里的网页（[browser.md](browser.md)）和 myco 桥，很多办公的东西都能做成网页：表格、多维表格、文档、幻灯片、表单、看板。思路是不让 agent 每次现写一个网页，而是做好**模板**，agent 和人都只往里写**数据**；用户也能自己做模板、上架、分享。

## 1. 三个概念

- **模板**：做好的网页。一个文件夹：网页文件 + `myco.json` 清单（名字、版本、数据结构、要的权限、给 agent 的说明）。不含任何人的数据，可以上架、分享、升级。
- **实例**：一次具体的使用 =「某个模板的某个版本 + 一份数据」。比如「Q4 招聘进度表」是「多维表格」模板的一个实例。放在项目或对话里，能置顶，人和 agent 都能打开、改数据。
- **套件**：几个模板 + 配套的 agent 技能 + 自动化，一次装好。官方的「工作套件」「编码套件」，或者用户自己做的「招聘套件」。

## 2. 整体架构

```
 人 · myco App                    工作区 Hub                          agent · 它的电脑
┌──────────────────────┐   取模板  ┌──────────────────────────┐        ┌──────────────────────┐
│ 实例网页（沙箱 iframe） │ ───────▶ │ 模板库：模板按版本存 zip    │        │ myco CLI              │
│ 只通过 myco 桥读写数据  │          │ 清单、权限、给 agent 的说明 │        │ app new / data get    │
│ 导出 Excel / PDF / PPT │          ├──────────────────────────┤  CLI   │ data patch / watch    │
├──────────────────────┤   读写   │ 实例和数据                 │ ◀────▶ │ template init/publish │
│ myco 桥                │ ◀──────▶ │ 集合 → 记录（按行改、带版本）│        ├──────────────────────┤
│ data · subscribe ·     │          │ 变化流、按清单校验、权限    │        │ 模板给它的说明（agent.md）│
│ send · download        │          ├──────────────────────────┤        ├──────────────────────┤
├──────────────────────┤          │ 文件：图片、附件、导出       │  叫醒  │ 连接器技能（可选）      │
│ App 后端（console）    │          │ 通知：人改了 → 合并成一条消息 │ ─────▶ │ 飞书 / 钉钉，用户的凭证  │
└──────────────────────┘          └──────────────────────────┘        └──────────────────────┘
                                         ▲ 装进来
                                  模板市场（以后）：官方套件、用户上架的模板
```

人和 agent 不碰对方的东西：人用网页，agent 用 CLI，两边改的是 Hub 上同一份数据。模板只管怎么显示，数据和权限在 Hub。

## 3. 一次改动怎么流动

1. 人在网页里改了一行：patch 第 12 行，基于第 41 版。
2. Hub 记成第 42 版；agent 在 `data watch`，收到变化（agent 没开着时，Hub 防抖后合并成一条消息叫醒它，内容只是数据）。
3. agent 补了数据：patch，基于第 42 版。
4. Hub 记成第 43 版；开着的网页订阅了变化，马上显示「agent 改了」。
5. 两边同时改同一行：后到的收到冲突和最新值，合并后再交。不同行互不影响。

## 4. 用户自己做模板

说出来（「帮我做个周报模板」，agent 用 `myco template init` 起脚手架）→ 边做边看（`myco page serve` 实时预览，用示例数据试，提意见它改）→ 发布（`myco template publish`，进工作区的模板库）→ 分享（工作区里的人都能用；分享链接给别人装；上架市场）→ 升级（发新版本，实例提示「有新版本」，数据按 `dataVersion` 迁移）。做模板不需要会写代码。

```
weekly-report/
├─ myco.json      清单
├─ index.html     界面（任何前端框架构建出来的都行）
├─ agent.md       给 agent 的说明：数据结构、怎么填、注意什么
└─ sample.json    示例数据（预览、市场截图）
```

```json
{
  "id": "glenn/weekly-report",
  "name": "周报",
  "version": "1.1.0",
  "kind": "doc",
  "data": {
    "items": { "fields": { "title": "text", "owner": "person", "done": "bool", "due": "date" } },
    "summary": { "single": true, "fields": { "text": "markdown" } }
  },
  "dataVersion": 2,
  "migrate": "migrate.js",
  "permissions": ["send", "download"],
  "export": ["xlsx", "pdf"],
  "agent": "agent.md"
}
```

## 5. 权限和安全

| 能力 | 默认 | 说明 |
| --- | --- | --- |
| 读写自己实例的数据 | 有 | 只能是这个实例，按清单的结构校验 |
| 以你的名义发消息（send） | 要声明 | 第一次发时问一次，和现在的网页一样 |
| 存文件到下载（download） | 要声明 | 导出 Excel / PDF 用 |
| 连外网（net） | 没有 | 要声明具体域名，经 Hub 转发，装的时候列出来 |
| 读别的实例、对话、令牌 | 永远没有 | 沙箱隔离，不同源 |

- 官方模板签名，市场里标「官方」；第三方模板标作者，上架前审核，装的时候列出它要的权限。
- 人在网页里写的东西，到 agent 那里都是数据，不是指令。
- 开了端到端加密的工作区先不开放（数据明文存在 Hub 上，和网页一样）。

## 6. 官方套件（第一批的想法）

- **工作套件**：表格（列有类型，筛选排序，导出 CSV / Excel）、多维表格（同一份记录，表格 / 看板 / 日历 / 画廊几种视图，表单收集）、文档（块编辑器，导出 Word / PDF）、幻灯片（agent 写大纲，自动排版，导出 PPT / PDF）；技能：飞书、钉钉同步（用你自己的凭证）。
- **编码套件**：任务看板、测试报告、代码评审（逐条批注，agent 改完打勾）、发版清单、设计预览（开发服务器的实时预览 + 批注）。

导出在模板里用浏览器端的库做（SheetJS / ExcelJS、docx.js、PptxGenJS，PDF 用系统打印），通过桥的 `download` 存到「下载」。数据本身是结构化的 JSON，agent 也能自己导出。

## 7. 和现在的东西怎么接

- 网页（已有）：实例就是一种网页，沿用沙箱、面板、标签、置顶、版本。
- 共享状态（已有，整份 JSON，最多 256KB）→ 升级成「集合 / 记录」，按行改、有变化流；老网页照常用。
- myco 桥（已有 ready / update / on / send / storage）→ 加 `data.*`、`subscribe`、`download`、`export`。
- 置顶（已有）：实例可以置顶到对话和项目。
- 手机：网页已经能在 iOS 里开，桥要补上。

## 8. 分几步做

1. 数据层（集合、记录、按行改、变化流、agent watch）、桥的 data / download、工作区内的模板库、`myco template init / publish`、`myco app new`。做完：用户让 agent 做模板，在自己工作区里用、给同事用。
2. 官方工作套件：表格、多维表格、文档；导出 Excel / PDF；实例置顶和项目里的入口。
3. 分享链接安装、版本升级和数据迁移、权限确认、编码套件、幻灯片。
4. 模板市场（官方 + 上架审核）、飞书 / 钉钉连接器、多人同时编辑文档（Yjs）。

## 9. 待定

- 市场放在哪：myco 官方的公共 Hub，还是只靠分享链接、工作区之间互相装？
- 模板能不能带在 Hub 上跑的脚本（比如定时汇总）？倾向不带，交给 agent 和自动化。
- 实例归谁：跟项目走、跟对话走，还是都支持？

## 10. 官方模板（第二步，已做）

随 Hub 一起提供（`internal/templates/official`，编进二进制），每个工作区的模板库里都有、排在最前、标「官方」，不能删，跟着 Hub 升级；`myco/` 开头的 id 留给它们。表格和多维表格用原生 JS（`kit.js`、`kit.css` 共用：按顺序存一个集合、别人改的实时合进来、冲突时换成最新的、同一条记录的写入排队；CSV 和不依赖任何库的 .xlsx 生成），浅色、深色都有，离线能用。

- **表格**（`myco/table`）：`sheet`（一条 main：标题、列）+ `rows`（每行 `cells` 按列 id 存、`order`）。列能加、改名、改类型（文本、多行、数字、日期、单选、勾选、人、链接）、删；按列排序、搜索（只在这个网页里，不存）；导出 Excel 和 CSV。
- **多维表格**（`myco/base`）：`base`（一条 main：标题、字段）+ `records`（`values` 按字段 id 存、`order`）。视图：表格、看板（按单选字段分组，优先「状态 / 阶段 / 进度」，拖卡片改值）、日历（按日期字段，按月翻）、画廊、表单（填好提交就是一条新记录）；点一条在右侧打开，所有字段都能改。导出 Excel 和 CSV。
- **文档**（`myco/doc`，v2）：对标飞书文档，编辑器用 [BlockNote](https://www.blocknotejs.org/)（MPL-2.0，基于 ProseMirror），源码在仓库的 `templates/src/doc`（React + Vite，`make templates` 构建进 `internal/templates/official/doc`）。`doc`（一条 main：标题）+ `blocks`（每个顶层块一条：`type` p / h1–h3 / li / ol / todo / toggle / quote / code / hr / table、`text` 纯文字、`checked`、`order`，`block` 是编辑器自己的完整格式：加粗、颜色、链接、嵌套、表格）。「/」菜单插入各种块，`#` `-` `1.` `[]` `>` 等 Markdown 快捷写法，选中文字出格式工具条，左侧把手拖动调整段落；停顿 0.5 秒保存，只写改了的块，两个人改不同块互不覆盖；agent 只写 `type` 和 `text` 也行，网页据此画出来；导出 Markdown 和网页。

每个模板都带 `agent.md`（怎么读写它的数据）和 `sample.json`（示例数据）。

**App 里的入口**：边栏「自动化」下面一行「模板」。页面上先是官方的三张卡片，再是这个工作区的模板（没有时说一句怎么让 agent 做一个），最后是「用模板建的网页」（点开就在网页面板里）。点一张卡片：填名字、选放在哪个项目（或不放进项目）、要不要先放示例数据，点「新建」，网页在面板里打开。
