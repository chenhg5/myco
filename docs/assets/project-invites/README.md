# Project coordinator invitations

Synthetic App screenshots, 1440 × 1000 at 2× (2880 × 2000 pixels).
Chinese/English use the same layout; light shows the project setting and dark
shows its one-time approval card. No real conversation or credential is present.

Regenerate from the repository root with the pinned separate apps checkout:

```sh
APPS_TEST_ROOT=/path/to/apps node web/scripts/media-kit-shots.mjs \
  --scene project-invites,project-invite-approval --out /tmp/project-invites
```
