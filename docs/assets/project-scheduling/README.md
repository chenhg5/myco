# Coordinator scheduling and bounded automations

Synthetic App screenshots, 1440 × 1000 at 2× (2880 × 2000 pixels).
The Chinese and English light pair shows the three coordinator permissions.
The dark pair shows start/end dates and a single execution in the editor.
No real conversations or credentials are included.

Regenerate with the pinned separate apps checkout:

```sh
APPS_TEST_ROOT=/path/to/apps node web/scripts/media-kit-shots.mjs \
  --scene project-scheduling,automation-window --out /tmp/project-scheduling
```
