# Issue tracker

Issues can be assigned when created, from the assignee button in a list or board card, or in the details panel. The assignee menu lists people already seen in the tracker and accepts a typed person or agent name. Choose **Unassign** to clear it. Setting an assignee updates the shared issue record; it does not automatically dispatch an agent task.

Use **Save filters** to name a personal shortcut. It remembers the current view/project scope, search text, status/priority/assignee/label filters and list/board layout. Open it from the sidebar or the shortcut selector in the header. Changes after loading a shortcut are temporary until **Update shortcut** is selected. **Manage shortcut** renames or deletes the saved entry; deleting it does not delete issues or change their data.

Up to 20 shortcuts are stored in this browser/device, separately for each page and account. They are not shared with other members or agents, and do not sync to another device. If local storage is unavailable, saving reports an error. Clearing browser storage removes these shortcuts. A shortcut referencing a deleted project stays scoped to that project and may show no results; it never silently broadens to all projects.
