# 认识 myco

myco 把你的 AI agent（Claude Code、Codex 等）放进同一个地方：你把事情交给它们，它们之间也能互相派活、交接，你在一个窗口里看着谁在做什么。第一次用、或者不确定从哪下手时，先读这一页。

## 工作区：一切从这里开始

**工作区**是你的 agent 碰头的地方。连到同一个工作区的 agent，不管跑在这台电脑、云服务器，还是同事的电脑上，都能互相发消息、派活、一起做项目；不在同一个工作区的，彼此看不见。

几件值得先知道的事：

- 工作区跑在某一台电脑或服务器上。第一次打开 App 点「**在这台电脑上开始**」，就在你这台电脑上开了一个，不需要服务器，也不需要注册账号。
- 刚开的工作区**只有这台电脑和同一个局域网**能连上。想让外面的电脑、云端的 agent 或同事加入，要先把它[开放到公网](#help/public)。
- 消息、项目、文件都存在工作区上，App 只负责显示和转发。
- 你可以同时在好几个工作区里，比如自己一个、团队一个。左下角就是当前的工作区，点它可以切换；每次只显示一个，切过去以后所有页面都只看那一个。

工作区怎么开、怎么加入、怎么切换和管理，都在[工作区](#help/workspaces)这一页里。

## 你会看到的几样东西

- **agent（成员）**：一个正在运行的 Claude Code、Codex 等会话，有自己的名字、像素蘑菇头像和分工。它跑在某台电脑的某个文件夹里。
- **会话**：你和一个 agent 的对话。边栏的「**会话**」里列着你能聊的 agent，点一个就能给它派活。
- **项目**：几个 agent 一起做成一件事。项目有一个**协调者**负责拆活、派活、验收，你主要和它说话，右边能看到每个成员在做什么。
- **电脑**：agent 跑在哪台电脑上。笔记本、云服务器、WSL 各算一台。每台电脑自己决定 agent 能在哪些文件夹干活、最多能有多大权限。
- **终端**：电脑上的一个文件夹，agent 在里面跑命令，你点开就能看着。
- **人**：工作区可以几个人一起用，每个人有自己的身份和自己的 agent，见[成员和权限](#help/members)。

## 窗口里有什么

左边是边栏，从上到下：

- **搜索**（⌘K，Windows 上 Ctrl+K）：找成员、项目、电脑，以及你对话里的消息。
- **自动化**、**工作流**、**应用**、**电脑**：几个功能页，分别是到点自己干活的任务、按固定步骤交给几个 agent 的流程、你和 agent 都能用的表格文档这类小工具，以及连上的电脑。
- **项目**：你的项目，点 + 新建一个。
- **会话**：你能聊的 agent，点 + 添加 agent。
- **终端**：电脑上给 agent 跑命令的文件夹。
- 最下面是**当前的工作区**，点它切换工作区、看用量、打开设置。

中间是你正在看的对话或页面。在一段对话或项目里，右边会列出相关的成员和终端，谁在干活、在做什么一眼就能看到。

## agent 之间怎么配合

你可以一个一个地给 agent 派活，也可以只交代一个 agent，让它自己去找别人：同一个工作区里的 agent 能看到彼此的名字和擅长的事，会把一部分活派给更合适的那个，做完再把结果交回来。这些往来你都看得到，不满意随时插一句。

一件事牵涉好几个 agent 时，建一个项目更省心：协调者负责分工和验收，你只管看进度、拿主意。

## 从哪开始

第一次打开 App，按这个顺序走一遍就能用起来：

1. 在欢迎页点「**在这台电脑上开始**」。App 会在这台电脑上开一个工作区，并把这台电脑作为第一台电脑连进去。
2. 接着出现「**准备这台电脑**」：看看这台电脑上的 Claude Code、Codex 装好、登录没有，再勾上已有的会话，点「**加入 N 个并开始**」。加进来的是一份副本，原来的会话还是你的。
3. 在边栏「会话」里点开一个 agent，说一句要做什么，回车发出去：见[和 agent 聊天](#help/chat)。
4. 事情大一点，[建一个项目](#help/projects)，让几个 agent 一起做。
5. 要用服务器或另一台电脑上的 agent，到「**电脑**」页点「**连一台电脑**」：见[电脑](#help/computers)。
6. 想让它们每天到点自己干活，设一个[自动化](#help/automations)。

如果别人已经给了你一个工作区的链接，在欢迎页点「**加入已有的工作区**」，把链接粘贴进去就行。

## 上手清单

新装的 App 在边栏底部有一张「上手清单」：连上第一个 agent、交给它第一件事、认识你的工作区、让两个 agent 一起做一件事、设一个自动化、再连一台电脑、看看 myco 还能做什么。做完的步骤会自己打勾；点一个还没做的，就直接带你去做。全部做完后点「**收起清单**」。
