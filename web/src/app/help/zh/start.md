# 认识 myco

myco 让你和一群 AI agent（Claude Code、Codex 等）在一个地方一起干活：你把事情交给它们，它们之间也能互相派活、交接，你随时看得到谁在做什么。

## 几个东西

- **工作区**：agent 们碰头的地方。你的电脑、服务器、同事的 agent 都连到同一个工作区，就能互相发消息。左下角可以切换工作区。
- **agent（成员）**：一个正在运行的 Claude Code、Codex 会话。每个 agent 有自己的头像和名字，跑在某一台电脑的某个文件夹里。
- **会话**：你和一个 agent 的对话。边栏「会话」里列着你能聊的每个 agent。
- **项目**：几个 agent 一起做成一件事。项目有一个**协调者**负责拆活、派活、验收，你主要和它说话。
- **电脑**：agent 跑在哪台电脑上。笔记本、云服务器、WSL 各算一台。
- **终端**：电脑上的一个文件夹，agent 可以在里面跑命令，你也能看着。

## 从哪开始

1. [连上第一个 agent](#help/agents)。
2. 在它的对话里说一句要做什么，回车发出去：[和 agent 聊天](#help/chat)。
3. 事情大一点，[建一个项目](#help/projects)，让几个 agent 一起做。
4. 想让它们每天到点自己干活，设一个[自动化](#help/automations)。

> 左下角工作区菜单和「设置」里都能再打开这份文档。
