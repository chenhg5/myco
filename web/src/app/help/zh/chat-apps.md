# 聊天软件：在飞书、Lark、Slack 里找 agent

> 这是预览功能：能用，但实际用得还不多，遇到问题请告诉我们。

每个 agent 都可以有自己的飞书、Lark 和 Slack 机器人，和语音聊天一样，一个 agent 对应一个。机器人就是这个 agent 本人，在聊天软件里跟它说话就行：
- 它用第一人称回你：「收到，我看看」「我想确认一下：……」「好了」。
- 进度在同一张卡片上更新。
- 它有问题，会在聊天里问你，你直接回复就是回答。
- 做完了，结果发回这段对话。

**像语音聊天一样接待。** 在 **设置 › 语音** 配好模型后，机器人和语音聊天用同一个模型：能直接答的（它是谁、在做什么、做到哪了、结果如何）马上答；要动手的事，它说一句「好，我来弄」就去做。没配模型时，每句话都直接交给 agent 去做。

**接待设定。** 每个机器人可以有自己的接待设定，和语音聊天分开：在 agent 资料的 **渠道** 页，点那个机器人那一行的 **接待设定**，写下对谁怎么说话、能答什么、不能做什么。机器人给主人以外的人用时（比如面向客户）尤其有用。主人以外的人交下去的活，也会带上这份设定，agent 做的时候同样遵守。

注意：设定只是给模型的指引，不是权限边界，别人有可能把模型说动、绕过它。谁能和机器人说话，由「谁能用」决定（见下文）；真正不能碰的东西，要靠 agent 自己的权限和项目设置来限制。

## 给 agent 绑定飞书机器人

1. 打开这个 agent 的资料，点 **详细信息**，切到 **渠道** 页。已经接入的渠道在 **已接入** 里，其余的在 **添加渠道** 里。
2. 在 **添加渠道** 里点 **飞书**，弹出一个二维码。
3. 用飞书手机 App 扫码，在手机上确认。飞书会建好这个机器人，你就是它的主人。
4. 弹窗自己关掉，几秒后飞书出现在 **已接入** 里，显示「在线」。

![绑定飞书：扫码](shot:member-chat-apps-feishu)

然后就可以用了：
- **私聊：** 在飞书里找到这个机器人，直接说要做的事。
- **群聊：** 把机器人拉进群，@它说要做的事。它在你这条消息下开一个话题回复；在这个话题里接着说就行，不用再 @。

## 绑定 Lark 机器人

Lark 是飞书的国际版，账号和应用都和飞书分开，所以有自己的二维码。在 **添加渠道** 里点 **Lark**，用 Lark 手机 App 扫码确认即可，其余和飞书一样。飞书的码不能用 Lark 扫，反过来也不行。

## 绑定 Slack 机器人

1. 在 **添加渠道** 里点 **Slack**。
2. 点「在 Slack 里创建」。Slack 的建应用页面已经把设置都填好了，选你的工作区，点创建。
3. 在 Slack 里点「Install App」装到工作区，把 **Bot User OAuth Token**（xoxb- 开头）粘到第一个框。
4. 在「Basic Information」里生成一个 **App-Level Token**，权限选 `connections:write`，把它（xapp- 开头）粘到第二个框，点 **连接**。
5. 连好后，Slack 那一行下面会给出一句 `/claim 码`。在 Slack 里私聊机器人，把这一句发过去，你就成了它的主人。

![Slack 连好，等你认领](shot:member-chat-apps)

在 Slack 里，`/` 开头的话会被当成 Slack 自己的命令，所以要写成 `/myco stop`，或者用 `!` 开头，比如 `!stop`。

## 在聊天里能说什么

| 你发 | 会发生什么 |
|---|---|
| 一句话 | 它来回答或去做；它正在做的话，就是补充（它在问你问题时，这句就是回答） |
| `/stop` | 让它停下 |
| `/new` | 下一句开一段新对话 |
| `/whoami` | 看你自己的用户 id |
| `/help` | 看这些用法 |

## 谁能用

一开始只有主人能通过机器人派活，别人发消息只会收到一句说明。想让同事也能用：
1. 请同事给机器人发 `/whoami`，拿到对方的用户 id。
2. 在这台电脑的终端里运行 `myco im allow --name feishu-<agent 名> --user 对方的id`。

所有任务都以你名下的机器人节点发出，agent 会当成是你的意思来做，所以只放行你信得过的人。

## 要知道的

- 只有能管理这个 agent 的人才看得到 **渠道** 页。
- 机器人跑在这台电脑上，由它的 runner 服务负责运行；电脑关机或睡眠时，机器人也就离线了。想一直在线，就在一台常开的电脑上绑定。
- 飞书、Lark 的 App Secret，Slack 的令牌，还有接待用的模型 key，都只存在这台电脑上，不会上传到工作区。
- 不用了就点 **解绑**。解绑只是这台电脑不再运行它，飞书或 Slack 里的应用还在，可以到那边删掉。
