# 聊天软件：在飞书、Slack 里找 agent

不在电脑前也能派活：在飞书或 Slack 里给机器人发一句话，它就交给你选的 agent。
- 进度在同一张卡片上更新。
- agent 有问题，会在聊天里问你，你直接回复就是回答。
- 做完了，结果发回这段对话。

## 连接飞书

1. 打开 **设置 › 聊天软件**。
2. 在「交给哪个 agent」里选一个 agent。
3. 在「飞书 / Lark」那一行点 **扫码连接**，页面上出现一个二维码。
4. 用飞书或 Lark 手机 App 扫码，在手机上确认。飞书会给你建好一个机器人，你就是它的主人。
5. 几秒后，「已连接」里出现「飞书 · 在线」。

![聊天软件设置，飞书扫码](shot:settings-chat-apps)

现在就可以用了：
- **私聊：** 在飞书里找到这个机器人，直接说要做的事。
- **群聊：** 把机器人拉进群，@它说要做的事。它在你这条消息下开一个话题回复；在这个话题里接着说就行，不用再 @。

## 连接 Slack

1. 在「Slack」那一行点 **连接**。
2. 点「在 Slack 里创建」。Slack 的建应用页面已经把设置都填好了，选你的工作区，点创建。
3. 在 Slack 里点「Install App」装到工作区，把 **Bot User OAuth Token**（xoxb- 开头）粘到第一个框。
4. 在「Basic Information」里生成一个 **App-Level Token**，权限选 `connections:write`，把它（xapp- 开头）粘到第二个框，点 **连接**。
5. 连好后，这一行会给出一句 `/claim 码`。在 Slack 里私聊机器人，把这一句发过去，你就成了它的主人。

![Slack 连好，等你认领](shot:settings-chat-apps-slack)

在 Slack 里，`/` 开头的话会被当成 Slack 自己的命令。所以命令要写成 `/myco agent 名字` 这样，或者用 `!` 开头，比如 `!stop`。

## 在聊天里能说什么

| 你发 | 会发生什么 |
|---|---|
| 一句要做的事 | 交给默认 agent；它正在做的话，补充给它（它在问你问题时，这句就是回答） |
| `/to 名字 要做的事` | 这一次交给另一个 agent |
| `/agent 名字` | 换这个聊天的默认 agent |
| `/agents` | 看谁在线 |
| `/stop` | 让它停下 |
| `/new` | 下一句开一段新对话 |
| `/whoami` | 看你自己的用户 id |

## 谁能用

一开始只有主人能通过机器人派活，别人发消息只会收到一句说明。想让同事也能用：
1. 请同事给机器人发 `/whoami`，拿到他的用户 id。
2. 在这台电脑的终端里运行 `myco im allow --name feishu --user 他的id`。

所有任务都以你名下的这个机器人节点发出，agent 会当成是你的意思来做，所以只放行你信得过的人。

## 要知道的

- 机器人跑在这台电脑上，由它的 runner 服务负责运行；电脑关机或睡眠时，机器人也就离线了。想一直在线，就在一台常开的电脑或服务器上连接。
- 飞书的 App Secret 和 Slack 的令牌只存在这台电脑上，不会上传到工作区。
- 想换默认 agent，在「已连接」那一行的下拉框里选；不用了就点 **断开**。断开只是从这台电脑上移除机器人，飞书或 Slack 里的应用还在，可以到那边删掉。
