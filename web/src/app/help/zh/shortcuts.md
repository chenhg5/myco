# 快捷键

完整的列表在「设置 › 快捷键」（或按 **⌘/**）。常用的几个：

| 做什么 | 按键 |
| --- | --- |
| 搜索对话、成员、项目和消息 | ⌘K |
| 后退 / 前进 | ⌘[ / ⌘] |
| 切换 agent（像 ⌘Tab） | ⌃Tab |
| 上一个 / 下一个对话 | ⌥↑ / ⌥↓ |
| 切换工作区 | ⌘1…9 |
| 新建项目 | ⌘N |
| 显示 / 隐藏边栏 | ⌘\ |
| 打开设置 | ⌘, |
| 在对话里找 | ⌘F |
| 添加文件 | ⌘U |
| 排到下一条 | ⌘回车 |
| 叫出 Shroom 小窗（Mac） | ⌘⇧空格 |
| 刷新 | ⌘R |
| 文字放大 / 缩小 / 标准 | ⌘= / ⌘- / ⌘0 |
| 切换浅色 / 深色 | ⌘⇧L |
| 关闭弹框、菜单和面板 | Esc |

## 输入框里

| 做什么 | 按键 |
| --- | --- |
| 发送 / 换行 | 回车 / ⇧回车 |
| 补充给正在做的事 | 回车（它在干活时） |
| 翻出之前发过的话 | ↑ / ↓（输入框为空时） |
| 填入 agent 建议的下一句 | Tab |
| 按住说话（Mac） | ⌥空格 |

## 终端里

| 做什么 | 按键 |
| --- | --- |
| 上一条 / 下一条命令 | ↑ / ↓ |
| 清屏 | Ctrl+L |
| 停止正在跑的命令 | Ctrl+C（输入框为空时） |

Windows 上把 ⌘ 换成 Ctrl、⌥ 换成 Alt。
