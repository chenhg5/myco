# 快捷键

完整的列表在「设置 › 快捷键」（或按 **⌘/**）。常用的几个：

| 做什么 | 按键 |
| --- | --- |
| 搜索对话、成员、项目和消息 | ⌘K |
| 后退 / 前进 | ⌘[ / ⌘] |
| 切换 agent（像 ⌘Tab） | ⌃Tab |
| 上一个 / 下一个对话 | ⌥↑ / ⌥↓ |
| 切换工作区 | ⌘1…9 |
| 新建项目 | ⌘N |
| 显示 / 隐藏边栏 | ⌘\ |
| 打开设置 | ⌘, |
| 在对话里找 | ⌘F |
| 添加文件 | ⌘U |
| 排到下一条 | ⌘回车 |
| 叫出 Shroom 小窗（Mac） | ⌘⇧空格 |

Windows 上把 ⌘ 换成 Ctrl、⌥ 换成 Alt。
