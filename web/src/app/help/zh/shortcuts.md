# 快捷键

App 里几乎每个常用操作都有快捷键，记住几个能省不少事。完整的列表在 **设置 › 快捷键**，随时按 **⌘/**（Windows 上 Ctrl+/）就能打开；下面和那一页一样分组，Mac 和 Windows 的按键各列一栏。

![设置 › 快捷键：App 里所有的快捷键](shot:settings-shortcuts)

在 Mac 上，⌘ 是 Command、⌥ 是 Option、⌃ 是 Control、⇧ 是 Shift。Windows 和 Linux 上用 Ctrl、Alt、Shift。快捷键暂时还不能自定义。

## 全局

在 App 的任何地方都能用。

| 做什么 | Mac | Windows |
| --- | --- | --- |
| 搜索：找对话、成员、项目和消息 | ⌘K | Ctrl+K |
| 后退 / 前进 | ⌘[ / ⌘] | Ctrl+[ / Ctrl+] |
| 切换 agent（像 ⌘Tab 那样） | ⌃Tab / ⌥Tab | Ctrl+Tab / Ctrl+\` |
| 上一个 / 下一个对话 | ⌥↑ / ⌥↓ | Alt+↑ / Alt+↓ |
| 专注模式（再按一次或 Esc 退出） | ⌘⇧F | Ctrl+Shift+F |
| 切换到第 1–9 个工作区 | ⌘1…9 | Ctrl+1…9 |
| 新建项目 | ⌘N | Ctrl+N |
| 显示 / 隐藏边栏 | ⌘\\ | Ctrl+\\ |
| 打开设置 | ⌘, | Ctrl+, |
| 查看快捷键 | ⌘/ | Ctrl+/ |
| 刷新 | ⌘R | Ctrl+R |
| 文字放大 / 缩小 | ⌘= / ⌘- | Ctrl+= / Ctrl+- |
| 文字恢复标准大小 | ⌘0 | Ctrl+0 |
| 切换浅色 / 深色 | ⌘⇧L | Ctrl+Shift+L |
| 关闭弹框、菜单和面板 | Esc | Esc |

几条说明：

- **搜索**：按下后屏幕上方出现一个搜索框，能找所有工作区里的成员、项目、电脑，以及你自己对话里的消息。↑↓ 选，回车打开。搜索框空着时，第一组是你最近打开过的对话，所以 ⌘K 再回车，就回到上一个对话。
- **后退 / 前进**：回到刚才看的页面，和顶栏的 ‹ › 一样；鼠标的侧键也行。
- **切换 agent**：按住 ⌃ 不放，按 Tab 或 ← → 挑一个（⇧Tab 往回），松开就打开。Mac 上 ⌃← → 被系统用来切换桌面，想用方向键就按住 ⌥。在浏览器里用 myco 时，用 \` 键代替 Tab。
- **上一个 / 下一个对话**：按边栏里的顺序，项目和会话都算。
- **切换工作区**：按左下角工作区列表的顺序，菜单里每个工作区旁边都写着它的快捷键。

![⌃Tab 切换 agent：按住 ⌃，按 Tab 挑，松开打开](shot:agent-switcher)

## 对话

| 做什么 | Mac | Windows |
| --- | --- | --- |
| 在这个对话里找 | ⌘F | Ctrl+F |
| 找到的上一处 / 下一处（在对话的查找框里） | 回车 / ⇧回车 | Enter / Shift+Enter |
| 添加文件 | ⌘U | Ctrl+U |

添加文件也可以直接粘贴，或把文件拖进输入框。分屏时，⌘F 找的是你最后点过的那一栏。

## 输入框

| 做什么 | Mac | Windows |
| --- | --- | --- |
| 发送 | 回车 | Enter |
| 换行 | ⇧回车 | Shift+Enter |
| 排到正在做的事后面 | ⌘回车 | Ctrl+Enter |
| 翻出之前发过的话（输入框是空的时候） | ↑ / ↓ | ↑ / ↓ |
| 填入 agent 建议的下一句 | Tab | Tab |
| 按住说话，松开结束（光标在输入框里时） | ⌥空格 / ⌃M | Ctrl+M |

- **排到后面**：agent 正在干活时用。直接回车是把这句话补充给它正在做的这件事；⌘回车 则等它做完这件再发。详见[和 agent 聊天](#help/chat)。
- **按住说话**：Windows 上 Alt+空格 会打开窗口菜单，所以用 Ctrl+M。详见[语音](#help/voice)。

## 终端

| 做什么 | Mac | Windows |
| --- | --- | --- |
| 上一条 / 下一条命令 | ↑ / ↓ | ↑ / ↓ |
| 清屏 | ⌃L | Ctrl+L |
| 停止正在跑的命令（输入框是空的时候） | ⌃C | Ctrl+C |

注意终端里在 Mac 上也是按 Control，不是 Command。终端的用法见[终端](#help/terminals)。

## 搜索框和设置

| 做什么 | Mac | Windows |
| --- | --- | --- |
| 在结果里上下选 | ↑ / ↓ | ↑ / ↓ |
| 打开选中的 | 回车 | Enter |
| 在设置里搜索（设置打开时） | ⌘F | Ctrl+F |

在设置里搜索时，中文英文都能搜，比如「字号」或「proxy」；按 Esc 先清空搜索框，再按一次关掉设置。

![⌘K 搜索：成员、项目、电脑和消息都能找](shot:search-anything)

## 只在 Mac 上

- **⌘⇧空格**：在任何地方（App 不在前台也行）叫出 Shroom 的小窗，一句话交给你的 superagent，见 [superagent](#help/superagent)。
- 屏幕顶上的菜单栏里也列着大部分快捷键（新建项目、搜索、边栏、文字大小、浅色深色……），忘了的时候可以去那里看一眼。
