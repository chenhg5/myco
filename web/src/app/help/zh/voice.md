# 语音

不想打字的时候，可以用嘴说。myco 里有两种语音：**语音输入** 把你说的话写进输入框，你看一眼再发；**语音聊天** 像打电话一样和一个 agent 实时说话，它听懂了就自己去办。

## 语音输入

输入框右下角、发送按钮左边的麦克风就是语音输入。不管框里有没有字，它都在。

1. 点一下麦克风，它变红、轻轻地闪，表示在听。
2. 说话。说的话会写进输入框，接在你已经打的字后面。中间停顿不会断，接着说就接着写。
3. 说完它会自己停；也可以再点一下停下。你一打字或发送，它也会停。
4. 看一眼，改一改，回车发出去。

![语音输入：麦克风变红，说的话写进输入框](shot:dictation)

听的语言跟着 App 的语言走：App 是中文就听中文，是英文就听英文，不跟系统。想换，在 **设置 › 外观** 里改 App 的语言。

**按住说话**：光标在输入框里时，按住 **⌥空格**（Mac）或 **⌃M** 说话，松开就停。

### 在 Mac 上

App 用苹果自带的语音识别（能在本机识别时就在本机）。第一次用时，系统会弹两个授权：「麦克风」和「语音识别」，都点允许。

如果点了不允许，麦克风按钮会变成橙色，鼠标移上去会告诉你去哪里打开：**系统设置 › 隐私与安全性 › 麦克风**（或 **语音识别**），把 myco 打开。

### 在 Windows 上

点麦克风后，App 先把这个窗口的输入语言切到 App 的语言，再打开 Windows 自带的语音输入（就是 Win+H 那个），由系统把字打进输入框。

按住说话在 Windows 上用 **Ctrl+M**（⌥空格 在 Windows 上会打开窗口菜单，所以换成了 Ctrl+M）。

### 看不到麦克风？

如果这台电脑上没有能用的语音识别（比如在不支持的浏览器里打开 myco），麦克风按钮就不显示。终端里也没有语音输入。

## 语音聊天

语音聊天就像给这个 agent 本人打电话（和 ChatGPT、Claude 的语音一样，一个对话一通）。接电话的就是它，它会说「我去改」「我看一下」：电话里它用一个反应很快的模型开口，真正的活还在它自己的会话里做。

- 接通后它先开口打个招呼，手上有活或在等你回答，会顺带提一句；
- 你问进展，它直接回答；
- 你要它做事，它就接下来：手上有活就补充进去，空着就作为一个新任务开始，和你按回车一样，不用再确认；
- 做完了或者有问题要问你，它挑安静的时候用一两句话告诉你，长的就说「详细的我写在对话里了」；
- 它在说的时候你一开口，它就停下来听。

语音聊天现在只在 **Mac 版 App** 和手机 App 里有。

### 先配好

打开 **设置 › 语音**：

1. **语音用的模型**：填 **地址**、**模型** 和 **密钥**。任何 OpenAI 兼容的接口都行（OpenAI、DeepSeek、豆包、OpenRouter……），挑反应快的就好：它只负责在电话里开口，难的活 agent 在自己的会话里做。不填就用「翻译」里配好的那个。
2. **语音合成**：负责把 agent 在电话里的话说出来。现在可以用 **豆包语音**：在火山引擎控制台的「豆包语音」里开通语音合成、创建 API Key，粘贴进来。
3. 选 **音色**（按语种分组）和 **语速**，点 **试听** 先听一句。用复刻的声音，音色选「其他（填音色 ID）」。
4. 点 **保存**。

![设置 › 语音：模型和语音合成](shot:settings-voice)

密钥存在这台电脑的系统钥匙串里，页面上只显示「已保存在系统钥匙串里（不显示）」。

最下面的 **多设备同步** 默认是开的：这些设置连同密钥会存到你连着的工作区，你的手机和别的电脑不用再填一遍。注意工作区所在电脑的管理员能读到它的数据；不想让密钥离开这台电脑，就把它关掉。

### 打一通

配好之后，对话输入框右边的圆按钮，在 **输入框是空的、agent 没在干活** 时会变成 **语音聊天**（波形图标）。

1. 点波形按钮接通。
2. 输入框上方出现一条语音栏：左边的小圆点表示状态（在听、在想、在说、已静音），旁边写着「和 xx 语音聊天」。
3. 下面是字幕，每行前面标着「你」或「语音」；它接下的事，会以一行带箭头的小字显示，比如「→ 开始做：核对下载页链接」。
4. 右边两个小圆按钮：**静音** 和红色的 **挂断**。按 **Esc** 也是挂断。

你通过语音交给 agent 的事，在对话里照常显示，气泡上方有个「经语音」小标，鼠标移上去能看到你的原话。

![语音栏：状态、字幕，以及转给 agent 的事](shot:voice-chat)

项目首页的输入框也一样：点波形按钮，会打开和收件人的对话并接通。

### 边走边聊

- 切到别的对话、项目或设置，通话不会断。顶栏右边会出现一个小胶囊，写着在和谁说、在听还是在说，也有静音和挂断；点名字回到那段对话。
- 同一时间只有一通。在另一个对话点语音，会先挂断前一通，按钮的提示会写「挂断和 A 的通话，改和 B 语音聊天」。

![通话收进顶栏右边的小胶囊](shot:voice-chip)

## 常见问题

**为什么看不到波形按钮？** 检查几件事：是不是 Mac 版 App；**设置 › 语音** 里的模型和语音合成是不是都配好了；输入框是不是空的；agent 是不是正在干活（这时圆按钮是停止）。终端的对话里没有语音聊天。

**录音会保存吗？** 不会。语音栏上的闲聊只留在这台电脑上，录音不保存；交给 agent 的事会作为普通消息留在对话里。

**它会不会听错就乱干活？** 它接下的事会写在字幕里，对话里那条消息也能看到原话。觉得不对，可以马上在对话里补充或停止，见[和 agent 聊天](#help/chat)。
