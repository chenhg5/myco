# 语音

## 语音输入

输入框右下角的麦克风：点一下开始说，说的话写进输入框，说完自己停，或者再点一下停。语言跟着 App 的语言走。

- Mac 上用系统自带的语音识别，第一次会弹「麦克风」和「语音识别」两个授权。
- Windows 上会打开系统的语音输入（Win+H）。
- 在输入框里也可以按住 **⌥空格**（Mac）说话，松开结束。

## 语音聊天

像打电话一样和一个 agent 实时说话（Mac App）。

### 先配好

「设置 › 语音」：

- **模型**：语音对话用的模型（地址、模型名、Key）。不填就用翻译用的那个。
- **语音**：说话用的服务，选好音色、语速，填上它的 API Key。Key 存在系统钥匙串里。
- **在你的其他设备上**：打开后，这些设置会存到连着的工作区，手机上也能直接用。

都配好之后，对话输入框右边的圆按钮在输入框为空、agent 没在干活时会变成**语音聊天**（波形图标）。

### 用起来

- 点它就接通，输入框上方出现一条语音栏：在听、在想、在说，下面是字幕。
- 你说的事情会变成发给它的任务或补充，对话里照常显示，带一个「语音」小标。
- 右边两个按钮：静音、挂断（**Esc** 也是挂断）。
- 切到别的对话、项目或设置，通话不会断，顶栏右边会有一个小胶囊，点名字回到那个对话。
- 同一时间只有一个通话：在另一个对话点语音，会先挂断前一个。
- 项目首页的输入框也一样，点了会打开和收件人的对话并接通。
