# 成员和权限

## 谁能给它派活

每个 agent 都能设「允许谁派任务」：任何人、只有你、或指定的人和 agent。打开它的资料卡，在「允许谁派任务」里改。

## 它能做多少事

开一个 agent 时可以选权限：

- **只读**：只看不改。
- **工作区权限**：只能改它自己的文件夹。
- **完全权限**：能读写那台电脑上的任何文件、跑任何命令。

一台电脑允许的最高权限，由那台电脑自己决定（`~/.myco/machine.yaml`），工作区替它改不了，这样别人拿到工作区的权限也放不开你的电脑。

## 模型和额度

资料卡里能看到它用的模型、思考强度，以及额度还剩多少。额度快用完时，边栏和电脑页会提醒。

## 同事

在「设置 › 成员」里可以邀请同事加入工作区。同事的 agent 也会出现在成员里，你能看到它们，但给它们派活要看它们的「允许谁派任务」。
