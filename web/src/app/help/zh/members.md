# 成员和权限

一个工作区可以几个人一起用：每个人有自己的身份、自己的 agent 和电脑。这一页讲怎么邀请同事、每种角色能做什么、多台设备怎么加，以及谁能看到、谁能使唤哪个 agent。

## 先说清楚：人和 agent

- **人**是用 App 的你和你的同事。人只存在于某个工作区里，没有注册，也没有密码：靠邀请链接加入，App 记住这台设备的凭据。
- **agent**是 AI 同事。每个 agent 都有一个**主人**：谁把它加进来，它就归谁。
- 同一个人在不同工作区里可以叫不同的名字。

人在「**设置 › 成员**」里管。打开简单模式时这一页是藏起来的，到「设置 › 外观」关掉「简单模式」就能看到。

## 三种角色

- **所有者**：工作区的主人，一个工作区只有一个。能管所有人、所有 agent 和电脑，能看工作区上的全部对话；只有他能开关端到端加密、做和下载备份。在这台电脑上开的工作区，所有者就是你。
- **管理员**：和所有者一样能管所有人、所有 agent 和电脑，能看全部对话和审计日志。
- **成员**：能看到团队可见的 agent，能给它们发消息；但只能管理自己加进来的 agent 和电脑。对话只能看到自己、或者自己的 agent 参与的那些，别人之间的对话看不到。

「设置 › 成员」最上面写着「你是 某某（角色）」。

## 邀请同事

先确认对方连得上这个工作区：本机工作区默认只在局域网里能连，对方不在你身边的话，先[开放到公网](#help/public)。

1. 打开「**设置 › 成员**」，点「**邀请成员**」。
2. 填**用户名**（小写字母、数字等，比如 `bob`）和**名字**（可选，比如「Bob」），选**角色**：成员或管理员。
3. 点「**生成邀请链接**」，把链接**私下**发给对方。

对方二选一：

- **不用装 App**：让自己电脑上的 Claude Code 或 Codex 运行弹窗里那条命令（或者直接对它说「接入 myco：<邀请链接>」）。它会装好 myco，以对方的身份加入，把那台电脑和执行命令的 agent 也接进来，都归对方管。以后想用 App 了，在那台电脑上运行 `myco member pair` 拿一个新链接。
- **用 App**：在 myco App 里点左下角的工作区 ›「加入或新建工作区」，粘贴链接。App 会问他在这个工作区上叫什么。

邀请链接只能用一次，24 小时内有效；用过或过期就作废，之后泄露也没用。

## 改角色、改名、移除

所有者和管理员在成员列表里能：

- **改角色**：每一行右边的下拉框，在成员和管理员之间切换。所有者还能选「**转为所有者**」，把工作区交给别人。
- **改名**：改用户名和名字。用户名是对方从 App 发出的消息的署名。
- **移除**：对方的 App 和命令行凭据立刻失效，他所有设备一起连不上。他加进来的 agent 和电脑会留下，可以在 agent 资料卡的「主人」里转给别人。

## 我的设备

同一个人可以在好几台设备上用：比如这台 Mac、家里的 Windows、手机。

1. 在「设置 › 成员 › **我的设备**」点「**添加另一台设备**」。
2. 在另一台设备的 myco App 里加入工作区时，粘贴这个链接；那台电脑不装 App 的话，也可以让那里的 agent 运行弹窗里的命令。
3. 链接只能用一次，24 小时内有效。

每台设备有自己的凭据，存在那台设备的钥匙串里，一直有效。设备丢了或不用了，在「我的设备」里点「**移除**」，它就再也连不上这个工作区。（打开简单模式时，「我的设备」在「设置 › 工作区」的最下面。）

## 谁能看到哪个 agent

每个 agent 有一个「**可见范围**」：

- **团队可见**：工作区里的人和 agent 都能找到它；谁能给它派活，再看「允许谁派任务」。
- **仅自己**：只有它的主人和主人自己的 agent 能找到它、给它派活。别人的 agent 看不到它，给它发消息会被拒绝；别人的回复照常能收到。所有者和管理员在列表里能看到它，但不能给它派任务。

成员自己加进来的 agent 默认是「仅自己」，所有者和管理员加的默认是「团队可见」。

要改：打开 agent 的资料卡，展开「**详细信息**」，在「运行」里点「**可见范围**」。只有它的主人和管理员能改，agent 自己改不了。

## 谁能给它派活

资料卡最下面「管理」里的「**允许谁派任务**」：选中几个 agent，就只有它们能给它派任务；一个都不选，就没有 agent 可以。保存时只增删你改动的条目；移除前会列出名字确认。你在 App 里亲自发的消息不受这个限制。只有它的主人或管理员能改。

## 项目的可见范围

项目也分两种（在项目设置里改）：

- **参与者可见**：项目的创建者、成员 agent 的主人和成员 agent 自己能看到；管理员也能看到。
- **团队可见**：工作区里所有人都能看到，也能把自己的 agent 加进来。

## agent 能动多少东西

agent 在电脑上能读写哪些文件，由它的「权限」（只读、工作区权限、完全权限）和那台电脑允许的上限一起决定。权限只有 agent 的主人能改（没有主人的由所有者改），管理员也没有额外的权利；电脑的上限只能在那台电脑上改，工作区替它改不了。详见[连上 agent](#help/agents)和[电脑](#help/computers)。

## 转交

所有者和管理员可以把一个 agent 转给别人：打开它的资料卡，在详细信息里点「**主人**」，选一个人，点「**转交**」。

## 审计

「**设置 › 审计**」记下谁在什么时候做了什么：邀请、移除、改角色、生成链接、在电脑上新建 agent、删除或踢下线 agent、从 App 派任务等。不记录消息内容，只能追加、不能修改。只有所有者和管理员能看，可以按人筛选。

## 常见问题

**同事打开邀请链接说连不上**：多半是工作区只在你的局域网里，先[开放到公网](#help/public)，再生成一个新的邀请链接。

**我看不到同事的某个 agent**：它的可见范围多半是「仅自己」，请它的主人改成「团队可见」。

**我能看到 agent，但给它派活被拒绝**：看它的「允许谁派任务」，请它的主人把你的 agent 加进去。

**同事离职了**：在「设置 › 成员」里移除他，再把他留下的 agent 和电脑转给别人。
