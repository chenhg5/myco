# 网络代理

如果你的电脑要通过代理（比如 Clash、V2Ray）才能上外网，在这里告诉 App 用哪个代理。App 连别处的工作区、检查更新、用翻译和语音服务时，都会走这里设的代理。

## 在哪设

打开「**设置 › 代理**」（左下角的工作区 ›「设置」，或按 ⌘, / Windows 上 Ctrl+,，在左边「这台电脑」一组里）。在设置顶上的搜索框里输入「代理」或「proxy」也能找到。

这一页是这台电脑自己的设置，不会同步到工作区，也不影响别人。

![设置 › 代理：手动设置一个本地 SOCKS5 代理](shot:settings-proxy)

## 三种选择

最上面有三个选项：

- **跟系统环境**（默认）：用环境变量里设的代理（HTTPS_PROXY、HTTP_PROXY、ALL_PROXY）；没有设就直接连。大多数人不用改。
- **不用代理**：所有连接都直接连，不走任何代理。代理软件开着、但你想让 App 绕开它时选这个。
- **手动设置**：自己填一个代理，下面细说。

Mac 上从程序坞或启动台打开的 App，通常读不到你在终端里设的代理环境变量。所以如果 Clash 一类的软件只是「开着」、App 却连不上外面，多半要选「手动设置」。

## 手动设置一个代理

1. 选「**手动设置**」。
2. **类型**：SOCKS5、HTTP 或 HTTPS，按你的代理软件提供的选。
3. **地址**：代理在哪台机器上。代理软件开在这台电脑上时，填 `127.0.0.1`。
4. **端口**：代理软件里写的端口。常见的有：
   - Clash 一类：HTTP 常见 7890，SOCKS5 常见 7891（有的版本是一个「混合端口」7890，HTTP 和 SOCKS5 都能用）；
   - V2Ray 一类：SOCKS5 常见 1080，HTTP 常见 1087 或 8080；Windows 上的 v2rayN 默认是 SOCKS5 10808、HTTP 10809。
   不确定的话，打开代理软件的设置看一眼。
5. **用户名、密码**：代理要登录才填，不用就空着。密码存在系统钥匙串里，保存后不再显示；要去掉它，点「**删掉密码**」。
6. 先点「**试一下**」：App 会用你填的设置连一次当前的工作区（没有工作区时连 GitHub），告诉你用了多少毫秒，或者为什么连不上。
7. 没问题就点「**保存**」。显示「已保存，马上生效」就好了，不用重启 App。

## 「试一下」没通过

- **12 秒内没有回应**：地址或端口可能填错了，或者代理本身连不出去。
- **代理拒绝了连接**：代理软件没在运行，或者端口不对。
- **找不到这个地址**：「地址」那一栏写错了。
- **代理要用户名和密码，或者没接受填的这组**：补上或改对用户名、密码。

手动设置的代理连不上时，App 的请求会直接失败，**不会**悄悄改成直连。所以代理软件关掉以后，记得回来切到「跟系统环境」或「不用代理」。

## 哪些走代理，哪些不走

**走代理**（选了「跟系统环境」且环境里有代理，或者选了「手动设置」时）：

- 连别的电脑或服务器上的工作区；
- 检查更新；
- 翻译服务和语音服务。

**从不走代理，总是直连**：

- 这台电脑自己的地址（`localhost`、`127.0.0.1`），比如这台电脑上的工作区；
- 局域网里的地址（`192.168.x.x`、`10.x.x.x` 这类，以及 `.local` 结尾的名字）。

这样即使代理软件没有排除局域网，这台电脑上和局域网里的工作区也照样能用。

## 只管 App 自己

这里的设置只影响 App。电脑上的 myco 后台、以及它唤醒的 Claude Code、Codex 等 agent，用的是它们自己的环境：

- agent 连不上模型（报「Network unreachable」「request timed out」）时，在设好了代理的终端里重新运行一次 `myco runner service install`，它会把终端里的代理设置一起写进后台服务。
- 想让别的电脑上的 agent 走代理，要在那台电脑上这样设。

## 手机上

iPhone 上的 App 也有「设置 › 代理」：默认跟着 iPhone 自己的代理和 VPN 设置，也可以选不用代理，或者手动填一个 SOCKS5 / HTTP 代理。用电脑上的 Clash 时，地址要填电脑在局域网里的地址（不是 127.0.0.1），并在 Clash 里打开「允许局域网连接」。

## 常见问题

**改了代理以后，有的页面还是连不上**：保存后马上生效，已经打开的连接会在空闲时换过去。等几秒再点一次「重试」。

**左下角的工作区显示「连不上」**：先在这里点「试一下」看代理通不通。工作区就在这台电脑上的话，和代理无关，到「设置 › 工作区」看它是不是停了，见[工作区](#help/workspaces)。

**把工作区开放到公网时一直在等**：一键开放第一次要下载 cloudflared，网络要走代理的话先在这里设好，见[开放到公网](#help/public)。
