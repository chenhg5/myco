# 终端

终端是一台电脑上的一个文件夹：agent 可以在里面跑命令，你打开就能看着，自己也能在里面敲命令。要让 agent 跑测试、构建、部署，或者想在手机够不着的服务器上随手执行几条命令时，就开一个终端。

## 终端在哪

- 边栏的 **终端** 一节，列着这个工作区里的每个终端，点一下打开。正在跑命令时右边有绿点；所有命令都可能卡住时变成橙点。
- 项目页右栏的「终端」，是加进这个项目的终端。
- 每台[电脑](#help/computers)页面的「Agent 和终端」里，列着这台电脑上的终端。

开着「简单模式」（设置 › 外观）时，边栏不显示「终端」这一节，但电脑页和项目里照样有。

## 开一个终端

入口有三个，打开的是同一个窗口：

- 边栏「终端」旁边的 **+**；
- 电脑页右上角的 **开终端**；
- 项目右栏「终端」旁边的 **+**（开好直接加进这个项目）。

步骤：

1. **在哪台电脑上**：选一台已经连上的电脑。还没允许 agent 跑命令的电脑，会标着「还没允许」。
2. **哪个文件夹**：填一个文件夹，比如 `~/code/我的项目`。这台电脑上用过的文件夹会列在下面，点一下就填好。
3. 点 **添加**。

开好以后它就出现在边栏「终端」里。从项目里开的，项目里所有 agent 马上就能用，后来加进项目的 agent 也能用；项目里还一个 agent 都没有时也能先开，等第一个 agent 进来就能用了。

### 电脑还没连上

选 **还没连上的电脑…**，App 给出一行命令（分 Mac / Linux / WSL 和 Windows 两种）。到那台电脑上，打开终端，**先进到要交给 agent 用的文件夹**，再运行这一行。它会顺便把这台电脑连进工作区，运行完这边会自己打勾。命令 24 小时内有效，只能用一次。

运行这条命令本身就是那台电脑的同意：agent 能用你的身份在这个文件夹里跑命令。所以用这种方式开的终端，不受下面「先允许」的限制。

### 先允许 agent 跑命令

一台电脑让不让 agent 在上面跑命令，由那台电脑自己决定，App 不能远程替它打开：

- 你正在用的这台：开终端的窗口里就有 **在这台电脑上允许**，点一下，确认就行。
- 别的电脑：在那台电脑上运行 `myco machine shell-access --allow`，或者在它自己的 myco App 里点「允许」。允许以后，这边会自己更新，**添加** 按钮就能点了。

允许之前想清楚：agent 在这台电脑上跑命令，就和你自己坐在电脑前一样。随时可以在同一个地方关掉。

## 在终端里敲命令

打开一个终端，整块深色面板就是它。最后一行是输入行，前面蓝色的是当前文件夹。

- **回车** 执行，**Shift+回车** 换行（写多行命令）。
- **↑ / ↓** 翻出这个终端里发过的命令。
- 命令在跑时，底部写着「正在执行 · Ctrl+C 停止」。输入框空着时按 **Ctrl+C**，或点这行字，就能停下。
- 输入 `clear` 或按 **Ctrl+L** 清屏。之前的内容不会丢：顶上有一行「已清屏 · 显示之前的内容」，点它就回来。清屏会记在这台电脑上，重开 App 也还在。
- 每条命令一行，输出紧跟在下面。上一条失败了，下一行的提示符会变红。
- 太长的命令会折起来，点命令本身展开，再点一下折回去。
- 鼠标放在命令上，能看到是谁、什么时候发的、用了多久、退出码。

这些快捷键在 Mac 和 Windows 上一样，都是 Ctrl。

## agent 怎么用终端

终端加进[项目](#help/projects)以后，项目里的 agent 都能在里面跑命令：你对协调者说「跑一下测试看看」，它会自己把命令交给终端。

- 想看 agent 们跑了什么：在项目右栏点这个终端，它会在协调者旁边打开一栏。agent 交给终端的活，在 agent 的对话里是一张张交接卡片，点开能看到它们之间的记录：谁、在什么时候跑了哪条命令，输出是什么。这些记录只能看，不能在里面输入。
- 一个终端可以同时在几个项目里。把它从项目里拿出来，那个项目的 agent 就不能再用它。

### 可能卡住的命令

别的 agent 发到这台电脑上、很久没有动静的命令，会在终端顶上用一条橙色的横条提示：「这台电脑上有 N 条命令可能卡住（来自某某）」。

- 点 **查看**，一条条列出来：命令、谁发的、安静了多久。
- 你能管这台电脑时，每条后面有 **停止**，横条上还有 **全部停止**。

你自己发的命令卡住了，会在那条命令上直接提示「可能卡住」，并给出 **停止** 和 **重发**。

## 终端的设置

终端顶栏右边的设置按钮、电脑页终端行上的 **设置**，或者在边栏右键一个终端，都能打开它的设置：

- **名字**：改成好认的名字，点 **改名**。
- **谁能在这里跑命令**：工作区里每个 agent 一个勾，勾完点 **保存**。勾了几个，就只给它们用；一个都不勾保存，就只有你自己能在终端里用。上面写着「现在任何 agent 都能用它」时，说明它还对所有 agent 开着。注意：勾上的 agent 能用你的身份在这个文件夹里跑命令。
- **在哪些项目里**：小标签上的 × 把它从项目里拿出来；**加进项目…** 把它放进另一个项目，项目里的 agent 就能用。
- **打开终端**：直接去终端面板。
- **移除这个终端**：确认后移除。agent 就不能再在这里跑命令了；文件夹里的东西不会动，聊过的内容都保留。

## 安全

- 终端里的命令以那台电脑上运行 myco 的用户身份执行，能做的事和你自己在那台电脑上一样多。只把终端交给你信任的 agent，用「谁能在这里跑命令」收紧。
- 只想给 agent 一个文件夹，就只开那个文件夹的终端；不要直接把整个用户目录交出去。
- 不想再让任何 agent 在这台电脑上跑命令：本机在电脑页的「权限」里点 **不再允许**；别的电脑在它上面运行 `myco machine shell-access --deny`。

## 常见问题

**「添加」是灰的？** 那台电脑还没允许 agent 跑命令，按上面「先允许」的说明做。

**命令一直没反应？** 那台电脑可能不在线，或者命令在等输入（终端不能回答交互式提问，比如要你输密码）。按 Ctrl+C 停掉，换成不需要交互的写法。
