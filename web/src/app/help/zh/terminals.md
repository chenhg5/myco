# 终端

终端是一台电脑上的一个文件夹：agent 可以在里面跑命令，你看着每一条命令和输出，自己也能在里面敲命令。

## 开一个

边栏「终端」旁边的 **+**，或在电脑页点「开终端」。选电脑和文件夹就好。

那台电脑要先允许 agent 跑命令：在电脑的「权限」里看。没允许时，App 会告诉你在那台电脑上运行哪条命令。

## 让 agent 用

把终端加进项目，项目里的 agent 都能在里面跑命令。终端右边的「设置」里能改谁能用、在哪些项目里。

## 自己用

- **↑ / ↓** 翻之前的命令。
- **Ctrl+L** 清屏。
- 输入框是空的时候按 **Ctrl+C** 停止正在跑的命令。
