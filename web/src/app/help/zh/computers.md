# 电脑

agent 总要跑在某台电脑上：你的笔记本、一台云服务器、Windows 里的 WSL，各算一台。把一台电脑连进工作区以后，你就能把它上面已有的 Claude Code、Codex 会话加进来，在它上面新开 agent、开终端，坏了也能在 App 里查原因、重启、升级。

## 「电脑」页

点边栏顶上的 **电脑** 进来。最上面三个数字：在线几台、一共几个 agent、几个终端。下面每台电脑一张卡片：

- 系统图标、名字；你正在用的这台带「这台电脑」小标签。
- 在线状态、系统、myco 版本。不在线的整张卡片是淡的。
- 底部一排小头像是它上面的 agent，后面写着几个 agent、几个终端。某个 agent 的额度快用完时，右下角会有一个橙色的「额度 95%」。

有电脑的 myco 不是最新时，列表上方会列出是哪几台，点 **全部升级** 一起升级（见下面「升级 myco」）。

![「电脑」页：每台电脑一张卡片，上方是需要升级的提示](shot:computers)

你用「在这台电脑上开始」建的工作区，这台电脑已经自动连上了，不用再加。

## 连一台电脑

点右上角的 **连一台电脑**，会打开「添加 agent」，停在「连一台电脑」这一格。顶上有三种方式，挑一种：

- **用 SSH 连**：你在这台电脑上平时能 `ssh` 登录的服务器，都可以这样连。
- **这台 Windows 里的 WSL**：只在 Windows 上、装了 WSL 时出现。
- **复制命令**：任何电脑都行，到那台电脑上运行一行命令。

### 用 SSH 连

1. App 读你的 SSH 配置（`~/.ssh/config`），每台主机一行。以前连过的标着「连过」。不在配置里的，点 **填一个不在配置里的**，填「用户名@地址」和端口。
2. 勾上要连的（可以一次勾几台），点 **连上**。
3. 每台电脑会走三步：登录，看看那台电脑 → 装好 myco，连上这个工作区 → 等它出现在工作区里。每一步有转圈、打勾或红叉。
4. 只连一台且成功时，窗口会自动切到那台电脑，列出它上面的会话。

App 只用你自己的 `ssh` 和 ssh-agent，不读、不存密钥，也替你输不了密码。如果登录要输密码或密钥口令，先用 `ssh-add` 把密钥放进 ssh-agent，确认在终端里不用输密码就能登录，再点 **重试**。第一次连某台主机，App 会让你先在终端里核对并接受它的指纹。出错时会用一句话说原因，给出可以复制的命令，还能展开「它最后打印的几行」。这种方式只能连 Linux 和 macOS；Windows 电脑请用「复制命令」里的 PowerShell 那条。

### 连 WSL

在 Windows 上选 **这台 Windows 里的 WSL**，列出每个发行版，标着「默认」和是不是「在运行」。勾上要连的，App 会进去装好 myco 并连上这个工作区；没在运行的会先启动。

### 复制命令

1. 选 **复制命令**，再选那台电脑的系统：**Mac / Linux / WSL**（一行 `curl`）或 **Windows（PowerShell）**。
2. 点 **复制**，到那台电脑上打开终端，粘贴运行。
3. 这边会显示「等它连上…」，连上后自动切到那台电脑。

命令 24 小时内有效，只能用一次，而且等同于凭据，别发到公开的地方。下面还有一句话，可以直接发给那台电脑上已经在跑的 agent，让它帮你连。

命令上方有时会出现一张提示卡，比如「只有同一个局域网里的电脑能连上」：说明你的工作区现在只在这台电脑和局域网里，云服务器连不进来。点卡片右边的 **开放到公网** 就能解决，详见[开放到公网](#help/public)。

## 一台电脑的页面

在「电脑」页点一张卡片。标题是电脑名字，下面一行是在线状态、系统和架构、主机名、myco 版本。右上角三个按钮：

- **开终端**：在它的一个文件夹里开一个终端，见[终端](#help/terminals)。
- **加 agent**：把它上面已有的会话加进来，或新开一个，见[添加 agent](#help/agents)。
- **⋯**：改名、移除。

回列表用顶栏左上的 ‹，或者再点一次边栏的 **电脑**。下面有四个标签页，每次都从第一个开始。

### Agent 和终端

这台电脑上的 agent 一行一个：在做什么、在哪个文件夹、在哪个项目、额度提示；点一行打开它的资料卡。下面是终端，每行有 **打开** 和 **设置**。还没有的话，会有一张说明卡和按钮带你去加。

### 权限

这一页说的是**那台电脑自己定的规矩**。规矩记在那台电脑上，不是工作区说了算，所以别的电脑上的人不能随便改。

- **agent 能在哪里开工**：新开的 agent 只能开在这些文件夹（和里面的文件夹）里。允许的文件夹显示成小标签。App 就装在那台电脑上，或者能用 SSH / WSL 连上它时，你可以直接在输入框里填一个文件夹点 **允许**，或点标签上的 × 不再允许，下一个新开的 agent 就按新的来，不用重启。连不上时，这里会给出要在那台电脑上运行的命令。
- **最高权限**：那台电脑上的 agent 最多能拿到多大权限：只读、只能改自己的文件夹，或完全放开。这一项同样只能在那台电脑上改。
- **让 agent 在这里跑命令**：开终端之前必须先允许。是你正在用的这台，就在 App 里点允许；是别的电脑，在那台电脑上运行 `myco machine shell-access --allow`，或者在它自己的 myco App 里点「允许」，这边会自己更新。

电脑不在线、或者它的 myco 太旧时，这些说不出来，页面上会写明原因。

![「权限」：允许的文件夹、最高权限、能不能跑命令](shot:computer-details)

### AI 和工具

一行一个 AI：Claude Code、Codex、Gemini CLI、OpenCode。右边是状态：**可用**、**没登录**、**没装**。下面一行写着它配了几个 MCP、几个技能、几个插件；点开能看到每一个的名字和来源。这里只列名字，不会显示任何密钥或地址参数。

想在这台电脑上装或登录某个 AI：你正在用的这台去「设置 › 本机 agent」；别的电脑，在「加 agent › 新开一个」里选它，会给出要在那台电脑上运行的命令。

### 检查和修复

电脑掉线了、agent 不干活了，来这里。App 要能用 SSH（或这台 Windows 里的 WSL）连上它：第一次会问「它是哪一个」，从 SSH 主机和 WSL 里选一个，点 **用这个**。之后这一行写着「经 SSH 某主机」，点 **换一个** 可以改。

- **检查**：看 myco 后台在不在跑、能不能连上工作区、日志最后说了什么。结果一条一行，绿、橙、红点表示好坏，最严重的在最上面；每条都写着该怎么办，需要时附上可以复制的命令。最后能展开「后台日志最后 20 行」。
- **重启后台**：重启那台电脑上的 myco 后台。
- **升级 myco**：下载新版本、换上、重启后台，一两分钟。

常见的发现有：后台没在跑；它连不上工作区的地址（多半是网络、防火墙，或工作区只在局域网里）；关掉 SSH 窗口后后台会被停掉；走了一个连不上的代理。

![检查和修复：一条条列出发现，附上怎么办](shot:computer-check)

## 升级 myco

电脑的 myco 旧了，它的页面顶上会写「不是最新」，点 **升级**。升级会重启它上面的 myco 后台，正在跑的任务会中断，挑个空闲的时候。「电脑」页上的 **全部升级** 一次升级所有能升级的。

- 电脑不在线：等它上线后再点，或者在那台电脑上运行 `myco upgrade`。
- 版本太旧、还不能从这里升级：在那台电脑上运行一次 `myco upgrade`（或者在「检查和修复」里设好 SSH 再升级），以后就能一键升级了。

## 改名和移除

- **改名**：**⋯ › 改名**，标题变成输入框，回车保存，Esc 取消。名字不能和工作区里别的电脑重复。改的是大家看到的名字，地址不变。
- **移除**：**⋯ › 移除**。弹窗会先列出它上面的 agent 和终端，它们会一起移除；聊过的内容都保留。那台电脑上的 myco 会被拒绝并停下；想彻底卸载，在那台电脑上运行弹窗里给的 `myco runner service uninstall`。移除不能撤销。

## 远程桌面

想直接看到、操作另一台电脑的屏幕，用应用库里的 **远程桌面**（在[应用](#help/apps)的「效率工具」里）。两台电脑都装着 myco App、在同一个工作区就行，不需要 agent。

1. 在要被控的电脑上新建一份「远程桌面」，切到 **共享这台电脑**。第一次要安装可选的远控组件，App 会先问你允许不允许。
2. 点 **开启共享**，页面上会显示一个配对码。默认只能看画面；想让对方操作键盘鼠标，开启前勾上「允许键盘和鼠标操作」。
3. 在另一台电脑（或 iPhone）上打开远程桌面，在 **连接电脑** 里选它，输入配对码。

Mac 被控时要在系统设置里允许 **屏幕录制**（才能看到画面）和 **辅助功能**（才能操作键鼠）。现在只支持同一局域网或 Tailscale 里、已经解锁的 Mac 和 Windows，没有声音，也操作不了锁屏和登录界面。配对码每次共享都会换，只给你信任的人；点 **停止共享** 或关掉这个应用，连接就断开。

## 常见问题

**电脑显示不在线？** 先看它有没有开机、有没有联网。再到它的「检查和修复」点 **检查**，按提示做。Mac 合上盖子睡着了也会显示不在线。

**连上了，但看不到它上面的会话？** 那个会话的文件夹可能不在「agent 能在哪里开工」里。到「权限」里允许那个文件夹再试。

**云服务器怎么都连不上？** 工作区多半只在你的局域网里，先[开放到公网](#help/public)。
