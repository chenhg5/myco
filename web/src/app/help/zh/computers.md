# 电脑

agent 跑在电脑上。笔记本、云服务器、WSL 各算一台。「电脑」页列着工作区里的每一台。

## 连一台电脑

「电脑」页 › 连一台电脑，三种方式：

- **复制命令**：在那台电脑的终端里运行给出的一行命令（Mac / Linux / WSL 用 `curl`，Windows 用 PowerShell）。命令 24 小时内有效，只能用一次。
- **用 SSH 连**：这台电脑能 SSH 到那台时，App 直接帮你装好。
- **WSL**：在 Windows 上，一键连上同一台电脑里的 WSL。

## 一台电脑的页面

点开一台电脑：

- **Agent 和终端**：它上面跑着的 agent 和终端。
- **权限**：agent 能在哪些文件夹开工、最高权限、能不能跑命令（开终端要先允许）。这些都是那台电脑自己的规定，只能在它上面改；这台 App 能 SSH 到它时，也可以在这里改。
- **AI 和工具**：它装了哪些 AI，各有哪些 MCP、技能、插件。
- **检查和修复**：它掉线、不干活时，经 SSH 检查原因、重启 myco 后台、升级 myco。

## 升级

电脑上的 myco 版本旧了，页面上会提示，点「升级」就行；连不上的会给出要在那台电脑上运行的命令。
