# 开放到公网

在这台电脑上开的工作区，一开始只有这台电脑和同一个局域网里的电脑能连上。开放到公网以后，云服务器、claude.ai 云端会话、在外面的笔记本和不在一起的同事都能连进来。

## 什么时候需要

本机工作区默认「只在本机/局域网」：同一个 Wi-Fi、同一个公司内网里的电脑可以直接连，别的都连不上。下面这些情况要先开放到公网：

- 想把一台**云服务器（VPS）**连进来，让 agent 在上面干活。
- 想让 **claude.ai 或 Codex 云端的会话**加入。
- **同事**不在你的局域网里，你想邀请他。
- 你带着笔记本或手机出门，还想连回家里这台电脑上的工作区。

App 会在用得到的地方提醒你：比如「电脑 › 连一台电脑 › 复制命令」上方会写「只有同一个局域网里的电脑能连上」，右边就有一个「**开放到公网**」按钮；「准备这台电脑」页的工作区卡片上也有「**让外面的电脑也能连**」。

## 打开它

1. 打开「**设置 › 工作区**」（左下角的工作区 ›「设置」，或按 ⌘, / Windows 上 Ctrl+,）。
2. 在「这台电脑上的工作区」里找到要开放的那个，点「**开放到公网**」。
3. 选一种方式（下面细说），点「**开放**」。

![开放到公网的三种方式](shot:open-to-internet)

## 三种方式

### 一键开放（推荐）

- **不用账号，也不用装别的**。第一次会自动下载 Cloudflare 的小工具 cloudflared（约 20 MB），以后就不用了。
- 得到一个 Cloudflare 的临时地址，形如 `https://<一串随机词>.trycloudflare.com`。
- 缺点是**地址不固定**：这台电脑重启后地址会变。到时回到这里再点一次就有新地址，但之前连进来的电脑和发出去的链接都会失效，要用新的重新连。

适合先试一试，或者只是偶尔让一台电脑临时连进来。

### Cloudflare 自己的域名（地址固定）

- 需要一个免费的 Cloudflare 账号，和一个托管在 Cloudflare 上的域名。
- 这台电脑上要先装好 cloudflared，并在终端里运行一次 `cloudflared tunnel login`，选你这个域名。没装 cloudflared 时这一项是灰的。
- 选中后在卡片里填一个域名，比如 `hub.example.com`，再点「开放」。
- 地址一直不变，重启也一样，适合长期用。

### Tailscale Funnel（地址固定）

- 需要一个免费的 Tailscale 账号，这台电脑上装好 Tailscale 并登录。
- 地址形如 `https://<电脑名>.<你的 tailnet>.ts.net`，一直不变。
- 还没装 Tailscale 也能选中它：下面会出现「**安装和连接 Tailscale**」，有官方下载、各系统的安装命令，也可以点「**让这台电脑上的 agent 帮我配置**」。装好、登录以后点「**我已安装，重新检测**」，再点「开放」。
- 第一次用 Funnel 时，Tailscale 可能要你在浏览器里授权、在 Tailscale 后台为这台设备打开 Funnel；系统要网络权限时也要你自己点允许。做完再试一次。

## 开放的过程

点「开放」以后，弹窗会显示正在做的三步和已经等了几秒：

- Cloudflare：下载或启动 cloudflared → 打通到 Cloudflare 的隧道 → 拿到公网地址，并确认外面能连上。通常 10–60 秒。
- Tailscale：为这台电脑打开 Funnel → 第一次会申请 HTTPS 证书 → 拿到 ts.net 地址。通常一两分钟。

不想等可以点「**取消**」，工作区照常在本机和局域网里能用。只有真的拿到公网地址、并且从外面确实连得上，才算成功；没成功的话会说原因，工作区保持原样，你可以再试一次。

![正在用 Cloudflare 开放：三步进度和已等的秒数](shot:open-to-internet-opening)

成功后弹窗不会自己关，会列出：

- **公网地址**：工作区在外面的地址。
- **入网链接**：别的电脑用它加入这个工作区。

两行旁边都有复制按钮。用的是一键开放时，下面还会提醒你这是临时地址。点「**完成**」关掉。之后「设置 › 工作区」里这个工作区的「访问」一行会写「Cloudflare」或「Tailscale」，下面是公网地址。

## 开放以后有什么变化

- 从这以后 App 里生成的东西，比如邀请同事的链接、「连一台电脑」的命令、开终端的命令，都会用公网地址，哪里的电脑都能用。
- **开放之前**生成、发出去的链接和命令还写着局域网地址，只在局域网里能用。要给外面的电脑用，回到那个弹窗重新生成一次（「复制命令」那里有「**开放好了，重新生成命令**」）。
- 这台电脑自己照常能用。开放以后，工作区只通过公网地址对外，不再直接听局域网的连接；局域网里之前用局域网地址连进来的电脑，要用新生成的命令再连一次。
- 这台电脑还是要**一直开着、不能睡眠**：它睡了，外面的电脑就都连不上了。Mac 上可以在「系统设置」的电池或能源设置里关掉自动睡眠。

## 关掉公网访问

App 里没有单独的「关闭公网」按钮。想让工作区回到只在本机和局域网能连：

1. 在「设置 › 工作区」里点这个工作区的「**停止**」。
2. 再点「**启动**」。重新启动的工作区是「只在本机/局域网」的。

停止期间别的电脑都连不上它；数据和令牌都保留。回到局域网以后，用公网地址连进来的电脑就连不上了，它们要在局域网里重新连。之后想再开放，点「开放到公网」重新来一次。

## 工作区在另一台电脑上

开放要在工作区所在的那台电脑上做。你在别的电脑上点「开放到公网」时，App 会告诉你三种做法：在那台电脑的 myco App 里「设置 › 工作区 › 开放到公网」；在那台电脑的终端里运行弹窗给出的命令；或者把弹窗里那句话发给那台电脑上的 agent，让它帮你开。

## 另一种做法：放在服务器上

如果你有一台有公网 IP 的 Linux 服务器，也可以干脆把工作区放在服务器上：它一直在线，不依赖你这台电脑开没开着，地址也固定。点左下角的工作区 ›「加入或新建工作区」›「还没有链接？」›「用 SSH 装到服务器上」，App 会帮你装好，见[工作区](#help/workspaces)。

## 安全须知

- 开放到公网，只是让外面**连得到**这个地址；没有令牌或链接，谁也进不来、看不到任何东西。
- **入网链接、邀请链接就是钥匙**：拿到它的人能把电脑或自己加进你的工作区。只私下发给要加入的人，不要贴到公开的地方。邀请同事的链接只能用一次，24 小时内有效。
- 每个人加入后有自己的凭据，管理员可以随时在「设置 › 成员」里移除一个人，他所有设备的凭据一起失效，见[成员和权限](#help/members)。
- 只在局域网里用时，连接是不加密的 HTTP，只在信得过的网络里这样用。开放到公网以后，外面用的是 HTTPS 地址。
- 几个人共用、又不想让工作区本身看到消息内容，可以在「设置 › 工作区」打开端到端加密。

## 常见问题

**一直停在「正在开放」**：一键开放第一次要下载 cloudflared，网络慢时会久一点；这台电脑上网要走代理的话，先在[网络代理](#help/proxy)里设好。等不及就「取消」，工作区不受影响。

**Tailscale 那一步没成功**：常见的是这台电脑上的 Tailscale 没启动或没登录，或者还没在 Tailscale 后台为这台设备打开 Funnel。弹窗会给出 Tailscale 自己说的原因和办法。

**重启以后别的电脑连不上了**：一键开放的临时地址变了。回到「设置 › 工作区」再点一次「开放到公网」，然后让那些电脑用新的命令或链接重新连一次。想一劳永逸，换成自己的域名或 Tailscale。
