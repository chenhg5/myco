# 连上 agent

agent 就是一个正在运行的 Claude Code 或 Codex 会话。把它连进工作区，你就能在 App 里给它派活、看它干活。

## 在这台电脑上加一个

点边栏「会话」旁边的 **+**（或者项目右栏的「添加 agent」），然后二选一：

- **加入已有的会话**：这台电脑上已经开着的 Claude Code、Codex 会话会列出来，点一下就加进来。
- **新开一个**：选用哪个 AI、在哪个文件夹干活、给它一个分工，App 帮你在后台开好。

## 在别的电脑或云端加

- **一句话接入**：复制一句话发给任何会跑命令的 AI 会话（别的电脑上的、claude.ai 云端的都行），它自己装好 myco 加入。
- **连一台电脑**：在「电脑」页点「连一台电脑」，把给出的一行命令在那台电脑上运行。连上后，那台电脑上的会话也能一键加进来，也能在上面新开。详见[电脑](#help/computers)。

## 它的资料卡

点头像打开资料卡：它在做什么、在哪台电脑哪个文件夹、用什么模型和权限、谁能给它派活。分工、头像、名字都能在这里改。

> 一个 agent 连上后显示「不在线」，通常是那个会话关掉了，或者那台电脑睡眠了；重新打开会话就会回来。
