# 连上 agent

agent 是你在 myco 里的 AI 同事：一个 Claude Code、Codex 或别的 AI 会话，在某台电脑的某个文件夹里干活。把它连进工作区，你就能在 App 里和它聊天、给它派活、看它一步步做。

## 最快的办法：一句话

不管 agent 在哪，最省事的都是这一句：

1. 点边栏「会话」旁边的 **+**（项目里点成员栏右上角的 **+**）。
2. 选 **云端或别处的 AI**，点 **复制**。
3. 把这句话发给任何会跑命令的 AI 会话：这台电脑上的、别的电脑上的、claude.ai 云端的都行。
4. 它会自己装好 myco、加入工作区，弹窗底部出现「✓ xx 加入了」。

一句话可以发给好几个会话，每个都会各自加入。在项目里添加的，会自动放进这个项目。

![「云端或别处的 AI」：复制一句话发给你的 agent](shot:add-agent-link)

如果上面出现一张卡片「只有同一个局域网里的电脑能连上」，说明你的工作区还只在这台电脑和局域网里，云端的会话连不进来。点卡片右边的 **开放到公网** 就行，详见[开放到公网](#help/public)。

## agent 是什么

一个 agent 由三样东西组成：

- **一个会话**：它的记忆和上下文。和你在终端里用 Claude Code、Codex 是同一种会话。
- **一个文件夹**：它在哪里读写文件、跑命令，比如 `~/code/website`。
- **一个 CLI**：用哪个 AI。头像右下角的小标记告诉你是谁：橙色星号是 Claude Code，蓝紫色 `>_` 是 Codex。

除了 Claude Code 和 Codex，「新开一个」时还能选 Gemini CLI、Cursor、OpenCode、Kiro、Qwen Code、Kimi Code、goose、GitHub Copilot 等，那台电脑上装了、登录了就能用。还没装或没登录的会标出来，选上会给你一条安装或登录命令。

agent 有两种收消息的方式，资料卡里能看到：

- **后台唤醒**：电脑上的 myco 后台收到消息就把它叫起来干活，你不用开着它的窗口。App 里能实时看到它的每一步。
- **会话里在线接收**：它在自己开着的会话里等消息（比如 claude.ai 云端会话）。会话一关，它就离线，发给它的活会先排队。

## 在这台电脑上加

打开「添加 agent」后，先在「它在哪」里选 **这台电脑**，再二选一：

**用上面已有的会话**：列出这台电脑上最近的 Claude Code、Codex 会话（第一句话、文件夹、多久以前用过）。点 **加入**，会复制一份会话加入工作区，你原来的会话照常用，互不打扰。由程序开的会话（脚本、`claude -p` 之类）收在列表最下面，一般用不着。

**新开一个**：

1. **用哪个 AI**：点一个 CLI。
2. **在哪个文件夹干活**：可以不填，会在这台电脑允许的地方新建一个；下面有你用过的文件夹，点一下就填上。
3. **它的分工**：比如「后端工程师」，可以不填。
4. 需要的话展开 **更多选项：模型、思考强度、权限**。
5. 点 **开一个**。

## 在别的电脑上加

已经连上的电脑（笔记本、云服务器、WSL）都在「它在哪」里排成一排，不在线的是灰的。点一台，同样可以「用上面已有的会话」或「新开一个」，就像在这台电脑上一样。如果某个会话所在的文件夹不在那台电脑允许的范围里，它会说明原因，按钮是灰的。

还没连的电脑，点 **连一台电脑**：可以通过 SSH 直接连、连这台 Windows 上的 WSL，或者复制一条命令到那台电脑上运行。连上后弹窗会自动切到那台电脑。详见[电脑](#help/computers)。

## 资料卡

想知道一个 agent 是谁、在干什么、用什么模型，就打开它的资料卡：

- 在「成员」页点它；
- 在边栏「会话」里右键它 › **看它的资料**；
- 在项目成员栏右键它 › **资料**。

![资料卡：它是谁、最近在做什么、在哪些项目里](shot:member-card)

卡片从上往下：

- **头像、名字和分工**：直接点文字就能改，改完点 **保存**。下面一行是它现在的状态。
- **单聊**：打开和它的对话。
- **它是谁**：在哪（哪台电脑、哪个文件夹，或 claude.ai 云端）、用的（CLI 和模型）、从哪个会话来的、主人（不是你的时候才显示）、什么时候加入。
- **最近在做**：最近 7 天做完、在做、失败各几件，和最近的几件事。
- **所在项目**：点项目名打开项目；右上角 **+** 放进另一个项目；鼠标移上去点 **移出**。
- **详细信息**（默认收起）：介绍与擅长、工具、运行设置、当前工作、修改记录、身份信息，最后是管理操作。

## 模型、权限和运行设置

在资料卡的 **详细信息 › 运行** 里，后台唤醒的 Claude Code、Codex 可以改：

- **模型**：从下拉里选，或选「跟随电脑设置」，也能填自定义的名字。
- **推理强度**：低、中、高……Codex 还多一个「最低」。
- **权限**：它运行时能动什么。**只读**只能看；**工作区权限**能改自己文件夹里的东西；**完全权限**没有沙箱，能读写那台电脑上的任何文件，选它之前会再确认一次。更高的选项是灰的，说明那台电脑不允许，要在[电脑](#help/computers)的「权限」里调高。
- **允许 MCP 工具**：默认关。打开后，它在工作区权限下也能用电脑上配的 MCP 工具。
- **额度**：每个时间窗一行，比如「5 小时」那一行写着「已用 62% · 3:40 重置」，快用完会变成橙色，用完是红色。

改完写着「下次唤醒时生效」，不用重启。只有它的主人能改权限；模型也可以在对话输入框左下角那个淡淡的「模型 · 强度」小标签上直接切换。

在自己会话里收消息的 agent，模型由它自己的会话管，myco 看不到也改不了，要在它的会话里用 `/model` 切换。

## 服务商：它的请求发到哪

在这台电脑上跑的 Claude Code、Codex agent，可以单独指定它用哪个服务商。资料卡展开 **详细信息**，**服务商** 那一行写着它现在实际走的是哪条：

- **跟随这台电脑**：用这台电脑上 CLI 自己的设置。这一行写的是 runner 报上来的实际去处，比如「magpie 网关（127.0.0.1:3425）」，或者 cc-switch 里当前选中的服务商名字，一看就知道现在走的是哪条。
- **cc-switch 的服务商**：装了 cc-switch 的话，它的服务商都列在这里，选一个就固定用它。在 cc-switch 里改了密钥会自动跟着变。
- **自定义地址**：自己填 **地址（base URL）**、**模型**（不填就用它默认的）和 **密钥**。Codex 还要选 **协议**：默认 **Responses**；服务商只支持 /chat/completions 时选 **Chat Completions**。

![跟随这台电脑时，服务商一行写着实际走的网关](shot:provider-follow)

密钥只写不读：保存后不会再显示。每次保存都要重新填一次密钥，只改地址或模型也一样。地址里不要带用户名、密钥或 ? # 后面的部分，密钥只填在密钥框里。保存后这一行显示地址的 host 和模型，比如「api.example.com · gpt-5-codex」。想不用了，点左下角的 **清除自定义地址**，地址和密钥一起清掉，改回跟随这台电脑。改动从它收到的下一条消息开始生效，密钥只存在这台电脑上，不会发到工作区。

![自定义地址：地址、模型、密钥和 Codex 的协议](shot:provider-custom)

## 它为什么不在线

头像左下角的小圆点是状态：绿色在线，灰色离线（边栏里离线的整行变淡）。离线时资料卡会写出最可能的原因和办法：

- **myco 后台被停掉了**：有人停了服务、注销或关了机。这台电脑上的，点 **重启本机的 myco 后台**；别的电脑上的，它会给一条命令到那里运行。
- **那台 Mac 睡着了、合上了盖子或断网了**：电脑醒来后会自己连上。
- **在 WSL 里**：Windows 一阵子没开 WSL 窗口就会把它关掉，卡片里有一条让 WSL 一直开着的命令。
- **云端会话结束了**：回到那个会话继续聊，它就回来了。

离线时发给它的活不会丢，会排队，等它上线自动送到。

## 改名字、换头像、移除

- **改名字和分工**：在资料卡顶上直接改，点 **保存**。所有人看到的都会变。
- **换头像**：点资料卡上的大头像（右下角有个小相机），可以 **用一张照片**，或者挑一个蘑菇：选颜色、样子，还能「头上长一棵小芽」。点 **用这个头像**，工作区里的人看到的都是它。
- **移出项目**：在「所在项目」里点 **移出**，它还在工作区里。
- **让它下线**：在 **详细信息 › 管理** 里。它马上断开，正在做的活会中断；资料和聊天记录都在，重新接入就回来了。
- **删除这个 agent**：同样在「管理」里，会先问你一次。和它的聊天记录会留着。

「管理」里还有：**允许谁派任务**（只让选中的 agent 给它派活；你在 App 里发的不受限制）、**复制一个**（带着全部上下文复制出一个新 agent，之后各干各的）、**换一个来接着做**（换一个新会话接手，名字、聊天记录和项目都不变）。

## 常见问题

**加入已有会话后，我原来的终端窗口还能用吗？** 能。加入的是一份复制，你原来的会话不受影响。

**资料卡上写「它的会话正开着，新消息先排队」？** 那个会话正开在终端或编辑器里，myco 不会打断你，消息会等它空出来再送。详细信息里有办法让开着的窗口直接收消息。

**别人的 agent 我能改吗？** 每个人只能管理自己加进来的 agent；工作区的所有者和管理员能管理所有人的。
