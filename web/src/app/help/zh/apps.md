# 应用

应用是你和 agent 一起用的网页工具：表格、多维表格、文档、幻灯片、任务追踪、白板，还有修图、剪视频、远程桌面和小游戏。你在 App 里点点改改，agent 用命令读写同一份内容，两边的改动实时同步；想让 agent 把结果整理成一张表、一份文档，或者给你一个可以点的页面时，就用应用。

## 应用库

点边栏顶上的 **应用** 进来。

- 右上角是搜索框「找应用」，旁边的刷新按钮会检查官方应用有没有新版本。
- **最近建的**：你最近建的几份，点一下就打开；有新版本的带一个小点。多了点 **全部** 展开。
- 一排分类：**全部 / 办公套件 / 编程开发 / 效率工具 / 生活 / 创意设计 / 游戏 / 这个工作区的**。下面按分类一格一格排开，每格是名字和两行介绍。

## 有哪些应用

- **办公套件**：
  - **表格**：像飞书表格一样一起填。列有类型（单选标签、日期、人员……），框选复制、从 Excel 粘贴、下拉填充，筛选、排序、搜索，导出 Excel 和 CSV。
  - **多维表格**：同一份记录，用表格、看板、日历、画廊、表单几种视图看，点一条在右侧展开。
  - **文档**：「/」插入标题、列表、待办、表格、代码块，导出 Markdown 和网页。
  - **幻灯片**：agent 写内容，网页按版式排好；点哪改哪，全屏放映，导出能接着改的 PowerPoint。
  - **会议记录**：录下线上会议，会后在这台电脑上转成文字并分出不同的人。
- **编程开发**：代码编辑器、任务追踪（像 Linear 那样管问题）、开发者工具箱。
- **效率工具**：待办清单、笔记、空间清理、远程桌面、代理工作台、行情工作台。
- **生活**：记账本、习惯打卡、影视。
- **创意设计**：白板、思维导图、设计工作台、修图、视频剪辑、动效视频、录屏工作台。
- **游戏**：五子棋、数独，可以和同事或 agent 一起玩。

不确定哪个合适，就看每格下面的两行介绍，或者在搜索框里搜你要做的事。

## 建一份

1. 点一个应用的卡片。
2. 弹出的窗口最上面是它的截图（几张的话，左右箭头翻看）。
3. **叫什么**：起个名字，比如「发布进度表」。
4. **放在哪**：
   - **不放进项目**：只有你和你的 agent 能看到。
   - 某个项目：项目里的人和 agent 都能用。
5. 点 **新建**。建好会直接在右边的面板里打开。

你在这个工作区第一次建某种应用时，会带上一些示例内容，让你看看它怎么用，不要的直接删掉；之后再建同一种就是空白的。每种应用空着也能用。

## 在面板里用

应用和 agent 发布的网页，都在同一个面板里打开：窗口宽时停在对话右边，窗口窄时盖在上面。

- 面板顶上是名字、第几版、谁发布的、多久以前；右边是刷新、复制链接、全屏和关闭。
- 拖面板的左边缘可以调宽。
- 再打开一个，会在面板里多一个标签页；最多 8 个，再多会关掉最早的。点已经开着的会切到它的标签，不会重新加载；切走再切回来，里面填了一半的东西还在。
- 想先把面板收起来，点面板顶上的 **收起**，网页都保留着；顶栏最右边会留一个「网页 N」，点它展开。只有 × 会把它们全部关掉。
- 页面上有新版本时，顶上会提示「有新版本：第 N 版」，点 **看新版本** 才换，你正在看的不会自己变。
- 官方应用出了新版本时，面板里会提示「有新版本……升级后数据不变」，点 **升级**。

应用跟着 App 的语言和浅色 / 深色走。你写的内容、起的名字不会被翻译。

## 让 agent 用

agent 能读写你建的应用：放在项目里的，项目里的 agent 都能用；没放进项目的，你自己的 agent 能用。直接在对话里说就行：

- 「把今天的进度填进『发布进度表』，每个人一行。」
- 「把刚才讨论的结论整理进那份文档。」
- 「看一下任务追踪里指给你的问题，改完把状态改成完成。」

它改了什么，你在面板里马上能看到；表格底下会写着是谁刚改的。

## agent 发布的网页

agent 也可以自己做一个网页发给你：一份报告、一张图表、一页可以勾的清单。你可以直接说「把这次的结果做成一个网页发我」。

它发布后，消息下面会出现一张网页卡片：名字、第几版、谁发布的、多久以前，右边是 **打开**。点卡片或链接，就在面板里打开。右键卡片可以：

- **置顶到对话上方**：常用的页面钉在对话顶上，随时打开。
- **复制链接**：发到对话里，能看到这个网页的同事在 App 里点开就是同一页。

agent 在它电脑上跑着开发服务器时，也能把它转发成「实时」网页：卡片上有一个橙色的广播图标和「实时 · 在线」的小标签，改了会自己刷新；它停了就显示「实时 · 离线」。消息里的 `http://localhost:…` 链接也会在面板里打开，那是这台电脑上正在跑的服务。

有的网页可以替你给 agent 发消息，比如清单页底下的「交给 agent」。第一次会先弹窗问你「允许这个网页以你的名义给某某发消息吗？」，并给你看要发的原话。点 **允许并发送** 以后，这次打开 App 期间它可以直接发，一分钟最多 5 条，发出的消息在你和它的对话里。

## 远程桌面

**远程桌面** 在「效率工具」里：在一台电脑上 **共享这台电脑**，另一台电脑或 iPhone 在 **连接电脑** 里选它、输入配对码，就能看到它的屏幕，允许的话还能操作键盘鼠标。怎么开、Mac 要给哪些权限、现在有哪些限制，见[电脑 › 远程桌面](#help/computers)。

## 自己做一个应用

官方的不够用，可以让 agent 给你做一个，比如：「用 `myco template init` 帮我做一个周报应用，做好发布到这个工作区。」做好的出现在分类「这个工作区的」里，工作区里的同事也能用它新建。

## 常见问题

**提示这个工作区还不能用应用？** 工作区的 myco 太旧，按提示升级工作区。

**网页一直空白？** 点面板右上的刷新再试一次；大一点的网页第一次打开要多等几秒。`localhost` 的页面空白，多半是那个端口上没有在跑东西。
