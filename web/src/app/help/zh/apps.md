# 应用

应用是现成的网页工具，人和 agent 一起用：表格、多维表格、文档、幻灯片、任务追踪、白板……你在 App 里打开编辑，agent 用命令读写，改动两边都看得到。

## 新建一份

「应用」页挑一个，点「新建」，起个名字、选放在哪个项目。这个工作区第一次建某种应用时，会带上一些示例内容让你看看怎么用，之后再建就是空白的。

建好的在「最近建的」里，点开在右边的面板里用。

## 让 agent 用

把应用放进项目，项目里的 agent 都能读写它。比如让 agent 把每天的进度填进一张表格，或者把讨论结果整理成文档。

## 自己做一个

跟 agent 说：「用 `myco template init` 帮我做一个周报应用，做好发布到工作区」。做好的出现在「这个工作区的应用」里，同事也能用。
