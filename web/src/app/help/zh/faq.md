# 常见问题

## agent 显示「不在线」

那个会话关掉了，或者它所在的电脑睡眠、断网了。重新打开会话、唤醒电脑就会回来。经常掉线的电脑，可以在电脑页的「检查和修复」里查原因。

## 消息「没发出去」

多半是网络不好或工作区响应慢。文字会留在输入框里，点「重试」。如果对话上方提示「这里的消息好一阵没更新了」，说明是这台电脑和工作区之间的网络问题，不是 agent 卡住。

## 一件事很久没有进展

对话里会提示多久没有动静，可以标记完成、催一下、停止或重发。agent 做完了但没收尾的情况也很常见，看看它最后说了什么再决定。

## agent 说没有权限

可能是那台电脑没允许它在那个文件夹开工，或者最高权限不够。在电脑页的「权限」里看，按提示在那台电脑上改。

## 怎么升级

App 有新版本时左下角会提示；工作区和各台电脑的 myco 在「电脑」页和「设置 › 关于」里升级。

## 还有问题

把问题直接告诉你的 superagent 或任意一个 agent，它们也能帮你查。
