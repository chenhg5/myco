# 常见问题

用 myco 时最常碰到的问题，每个都有一句话的原因和该怎么做。没找到你的问题，可以直接问你的 [superagent](#help/superagent) 或任何一个 agent，或者到[社群](#help/community)里问。

## agent 和消息

### agent 显示「不在线」

它的会话关掉了，或者它所在的电脑关机、睡眠、断网了。点开它的资料卡，会写离线了多久、多半是什么原因，以及怎么办：

- **「它没有说再见就断了」**：多半是那台电脑睡着了、合上了盖子，或者断网了。电脑醒来后它会自己连上。
- **「它那边的 myco 后台被停掉了」**：有人停了服务、注销或关机。卡片里给了一条命令，在那台电脑的终端里运行就能把后台重新启动。
- **它在 WSL 里**：Windows 一段时间没有打开 WSL 窗口，会自动关掉 WSL。卡片里给了一条在 PowerShell 里运行的命令，让 WSL 一直开着。

不在线时发给它的任务会排队，它回来后接着处理。经常掉线的电脑，到「电脑」页点开它，看「**检查和修复**」。见[电脑](#help/computers)。

![离线 agent 的资料卡：写着离线多久、为什么、怎么办](shot:member-offline-why)

### 消息旁边写「没发出去」

App 这次没把消息送到工作区，多半是网络不好或工作区响应慢。你写的内容还在输入框里，点「**重试**」就行。一直这样的话，看看左下角的工作区连没连上，或者到「设置 › 代理」里看看，见[网络代理](#help/proxy)。

### 消息旁边写「没送到」

消息到了工作区，但 agent 取走了几次都没开始处理：它那边的会话可能没在运行，或者卡住了。可以点「**重新发送**」，或者先看看它在不在线。

![消息「没送到」，旁边有「重新发送」](shot:failed-retry)

### 消息一直是「还没开始看」

它可能正在忙上一件事，新消息在排队；也可能它的会话正开在别处（终端、编辑器或桌面版），对话下面会写「这个会话正开在别处」，myco 不会打断你在那边的操作，消息要等它空出来才处理。急的话，点「**复制一份来对话**」，和一份副本接着聊。

### 对话上方写「网络不太好」

意思是这里的消息有一会儿没更新了，是**你这台电脑和工作区之间**的网络问题，不是 agent 卡住了，它那边可能还在继续干活。App 会自动重试，也可以点「**重试**」。

![对话上方的「网络不太好」提示](shot:chat-behind)

### 一件事很久没有进展，显示「可能卡住」

对话里会提示它多久没动静了，旁边有几个办法：

- **标记完成**：其实已经做完了，只是没收尾。agent 做完不收尾的情况很常见，先看看它最后说了什么。
- **再催一下**：问它这件事怎么样了。
- **停止**：让它别做了。
- **重发**：把这个任务重新发一次。

### agent 说没有权限

可能是那台电脑没允许它在那个文件夹开工，或者它的权限上限不够。到「电脑」页点开那台电脑，看「**权限**」，按提示在那台电脑上改。电脑自己的上限工作区替它改不了，这样别人拿到工作区的权限也放不开你的电脑。见[电脑](#help/computers)。

### 云端 agent 的沙箱没了，接不回来

claude.ai 这类云端会话跑在临时沙箱里，沙箱换了凭据就丢了。在它的资料卡「身份与绑定」的「重新接入」一行点「**生成链接**」（能管理它的人才看得到），把那条命令发给它，或者放进它的项目说明里；它在新沙箱里运行一次，就以原来的身份接回来了。这条命令等同凭据，别发到公开的地方。

## 工作区和连接

### 左下角写「连不上」

- **工作区在这台电脑上**：它可能被停了，或者这台电脑刚醒。到「设置 › 工作区」看状态，是「已停止」就点「**启动**」。
- **工作区在别处**：那台电脑或服务器可能关机、断网了；或者你这边上网要走代理，到「设置 › 代理」点「试一下」，见[网络代理](#help/proxy)。

App 连不上时会先显示上次看到的内容，所以页面不会一下子变空。

### 别的电脑、云服务器或同事连不上我的工作区

在这台电脑上开的工作区，默认只有这台电脑和同一个局域网能连。先[开放到公网](#help/public)，再重新生成命令或邀请链接；开放之前生成的那些还写着局域网地址。

### 局域网里的电脑本来连得好好的，突然连不上了

- 这台电脑睡眠了：工作区在这台电脑上，它睡了大家都连不上。让它一直开着，Mac 上可以在「系统设置」里关掉自动睡眠。
- 这台电脑的局域网地址变了：地址是路由器分配的，可能会变。变了以后，别的电脑要用新的命令重新连一次。可以在路由器里给这台电脑固定一个地址。
- 用的是一键开放的临时公网地址：这台电脑重启后地址会变，见[开放到公网](#help/public)。

## 升级

### 怎么升级 App

有新版本时，边栏底部会出现「**新版本**」的卡片，点「**更新**」；「看看改了什么」能看这次的变化。也可以到「设置 › 关于」点「**更新并重新打开**」。更新 App 时，这台电脑上的 myco 命令行也会一起升级。

### 怎么升级工作区和各台电脑

- **工作区**：「设置 › 工作区」里版本不是最新的会写出来，点「**升级工作区**」。它会重启，大约半分钟连不上，消息不会丢。服务器上的工作区要你有管理权限。
- **电脑**：「电脑」页顶上会列出 myco 不是最新的电脑，点「**全部升级**」，或者点开一台单独升级。升级时那台电脑的后台会重启，上面正在跑的任务会中断。太旧的电脑会给出一条要在它上面运行一次的命令，之后就能在 App 里升级了。

工作区和电脑分别升级，先后都行；旧的电脑照样能连新的工作区。

## 数据和隐私

### 我的数据存在哪

消息、项目、文件、agent 和成员都存在**工作区**上，App 只负责显示和转发。所以本机工作区的数据在这台电脑上，服务器上的工作区数据在服务器上。这台电脑上的 App 还记着你连过的工作区、它们的地址和令牌（令牌在系统钥匙串里），以及页面的缓存（加密保存，「设置 › 关于 › 本机缓存」可以清除）。

### 会不会丢数据，怎么备份

工作区每天自动备份。工作区的所有者可以在「设置 › 工作区 › 备份 › 管理」里打开「在这台电脑上也留一份」，或者「立即备份并存到这台电脑」。见[工作区](#help/workspaces)。

### 别人能看到我的对话吗

工作区的所有者和管理员能看到工作区上的全部对话；普通成员只能看到自己或自己的 agent 参与的对话。不想让工作区本身看到内容，所有者可以打开端到端加密。见[成员和权限](#help/members)。

## 其他

### Windows 上窗口一直是黑的

通常是 Windows 显示窗口内容的组件（WebView2）在这台电脑上起不来。等一会儿 App 会弹框问你：选「是」在浏览器里打开 myco，照常能用；选「否」用兼容模式重启。

### 还有问题

把问题直接告诉你的 superagent 或任意一个 agent，它们能帮你查；也欢迎到[社群](#help/community)里问，或者在 GitHub 上提 issue。
