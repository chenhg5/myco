## 反馈问题

遇到 bug 或想要新功能，欢迎在 [GitHub Issues](https://github.com/myco-ai/myco/issues) 里提。写清楚这几样，能更快解决：

1. 你做了什么，期望发生什么，实际发生了什么；
2. App 的版本（「设置 › 关于」里能看到），用的是 Mac、Windows 还是 Linux；
3. 有截图或报错的话一起贴上。

贴之前看一眼，别把令牌、链接或 API 密钥贴出去：入网链接和邀请链接都等同钥匙。
