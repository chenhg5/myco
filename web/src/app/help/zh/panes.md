# 分屏

想同时看几个 agent 干活，可以把对话分成几栏，最多四栏。项目和「会话」页都可以。

## 打开新的一栏

- **右键**一个成员（右边成员栏、收起后的头像条、边栏「会话」列表都行）› **在新的一栏打开**：最大的那一栏对半分开。
- **拖**一个成员到对话上：放在某一栏的左、右、上、下边缘，就把那一栏分开；放在整个区域的最外沿，就在那一侧加一整栏；放在一栏中间，就是「换成它」。松手前会亮出它会落在哪、会怎样。

点一个成员时，如果它已经开着，就跳过去；没开就换掉你最后点过的那一栏。

## 调整

- 栏与栏之间的线都可以拖，双击回到对半。
- 每一栏的标题上可以「只看这一栏」放大，再点一次回来。
- 关掉一栏，旁边的会补上它的位置。

## 小提示

- 切换右边那一栏的 agent 时，左边的对话保持不动。
- 窄窗口放不下时，成员栏会收成标题下面的一排头像。
