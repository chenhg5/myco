# 分屏

分屏就是把对话区分成几栏，同时看几个 agent 干活，最多四栏。一边和协调者说话、一边盯着两个成员，或者对照着看两个 agent 的回复时，就用得上。

## 在哪里能分屏

**项目** 和边栏的 **会话** 页都能分屏，用法一样。

- 第一栏属于这个地方本身：在项目里是你和协调者的对话，在「会话」页是那里的列表或你点开的对话。
- 其他几栏是你另外打开的成员，每一栏都是一段完整的对话，能看、能发、能停。

每栏的标题一样高，底边对齐，看起来像一排窗口。

![两栏并排：左边是协调者，右边是一个成员](shot:project-member-handoffs)

## 点一下：换掉一栏

在成员栏里点一个成员：

- 它已经开着，就跳到它那一栏；
- 还没开，就在你最后点过的那一栏里换成它（第一次点会在右边开一栏）。

所以只想「左边协调者、右边轮流看成员」的话，一直点就好，不会越开越多。

## 多开一栏

有两种办法。

**右键**：在成员栏、收起后的头像条，或边栏「会话」列表里右键一个成员 › **在新的一栏打开**。最大的那一栏会沿长边对半分开：宽的左右分，高的上下分。

**拖进来**：按住一个成员，拖到对话区上。松手前，它会落在哪里会亮起来，并写着会怎样：

- 放在某一栏的 **左、右、上、下边缘**：只把这一栏分成两半。比如左右两栏时，放在左栏的下边缘，左边变成上下两栏，右边不动。
- 放在整个对话区的 **最外沿**：在那一侧加一整栏，比如「在最下面多开一栏，横跨整个」。
- 放在某一栏的 **中间**：**换成它**（第一栏不能换）。

新开的一栏和同方向的栏平分空间：下面已经有两栏时，新的一栏占三分之一。

拖不进去的地方是灰的，并说明原因，比如已经四栏时会写「最多四栏：放到一栏中间换掉它」。拖一个已经开着的成员进来，它所在的那一栏会亮成橙色，写着「xx 已经开着了」，松手也不会再开一次。

## 调整大小和关掉

- **拖分隔线**：栏与栏之间的竖线、横线都能拖，每条线只管它两边的那两块。双击一条线，回到对半。
- **只看这一栏**：每栏标题右边有个放大按钮，点一下这一栏占满整个对话区；再点一下（「还原所有栏」）回来。
- **关掉这一栏**：另外打开的栏标题右边有 ×。关掉后，和它一起分出来的那一块会补上空位。

## 放不下的时候

每一栏至少要 320×240 那么大。窗口太小、放不下几栏并排时，几栏会变成顶上的一排 **标签**：一次只看一栏，点标签切换，另外打开的标签带 ×，新开的那个自动选中。

![窗口放不下时，几栏变成顶上的标签](shot:project-panes)

成员栏只在实在放不下「几栏并排加成员栏」时，才收成标题下面的一排头像；否则它不动，打开成员时页面不会跳。

## 它会记住

- 开了哪几栏、怎么分的，会按项目（和「会话」页）分别记在这台电脑上，下次回来还是这样。
- 在边栏里 **再点一次** 当前项目，会回到只有第一栏的样子。
- 一栏换了位置，里面的对话不会重新加载；切换某一栏里的 agent，别的栏不受影响。

## 小提示

- 按 **⌘F**（Windows 上 Ctrl+F）在对话里找，找的是你最后点过的那一栏。
- 每一栏可以有自己的聊天背景，分栏时各自铺满、裁边，不会变形，见[和 agent 聊天](#help/chat)。
- 想看两个成员之间说了什么，点项目首页的交接卡片，它们的往来也会在旁边一栏打开，见[项目](#help/projects)。
