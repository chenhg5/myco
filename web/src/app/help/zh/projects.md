# 项目

一个项目就是一件要做成的事，和一起做这件事的几个 agent。一件事一个 agent 就能搞定，直接聊就好；要几个 agent 分工合作，比如一个写代码、一个写文档、一个测，就建一个项目。

## 先聊，还是先建项目

不用一上来就建项目。边栏的「会话」页放的是还没进任何项目的 agent：

- 点一个 agent 和它单聊；
- 或者在「会话」页底部的输入框里派活：先在 **发给** 那里选一个会话，只有它会收到这条，其他会话看得到但不会动手。

![「会话」页：还没进项目的 agent，在这里直接派活](shot:loose)

等你发现几个 agent 要围着同一件事转，再建个项目把它们放进去。已有的 agent 右键 › **放进项目**，选一个项目就行；在它的资料卡「所在项目」旁点 **+** 也一样。

## 建一个项目

1. 点边栏「项目」旁边的 **+**，或按 **⌘N**（Windows 上 Ctrl+N）。
2. 写 **项目名**。
3. 写 **目标**（可选）：做什么、什么时候做完、做到什么程度算完。协调者和会话都会看到，以后在「项目资料」里随时能改。
4. 放上 **项目资料**（可选）：需求文档、设计稿、约定、截图都行，每个 20 MB 以内，拖进虚线框或点一下选择。
5. 点 **建好了**（带文件时是「建好，并上传 N 个资料」）。

![新建项目：项目名、目标和资料](shot:dialog-new-project)

新项目是空的，中间写着「项目建好了，拉几个 agent 进来吧」，点 **添加 agent**。可以加工作区里已有的，也可以在某台电脑上新开一个，或者复制一句话给别处的 AI，详见[连上 agent](#help/agents)。

## 协调者

每个有 agent 的项目都有一个 **协调者**，名字旁边带着「协调者」小标签。第一个加入的 agent 自动成为协调者。

你只需要和协调者说话：告诉它要什么，它把事情拆开分给会话，盯着进度，验收结果，最后回来告诉你。所以 **项目首页就是你和协调者的对话**：最上面是项目名和目标，下面就是聊天。空着的时候会给你几条例子，比如「把这个项目要做的事拆成几步，分给大家」「让每个会话说说自己现在在做什么」。

协调者比普通会话多一些权限：能改项目说明、文件和资料链接，能改其他会话的介绍和擅长，还能在你允许的电脑上开新的 agent（见下面）。

想换一个协调者：在会话栏右键一个会话 › **设为协调者**。原来的协调者被移出项目时，下一个最早加入的会自动接上。

## 会话栏

项目右边是会话栏，标题是「会话 N」。每个会话一行：名字、它现在在做什么，下面一行小字是「谁派的 · 多久之前 · 还有几个排队」。

排列顺序是：协调者在最上面，然后是正在干活的（刚开始的在前）、有活排着的、空闲的，离线的在最下面；同一类里最近活跃的在前。所以一眼扫过去，最上面几个就是现在最忙的。

- **点一个会话**：在协调者对话的右边打开它这一栏，里面是它收到的所有活（协调者派的、你派的，按时间排）和每件活的过程。在这里发消息，就是直接给它派活，协调者不会收到。
- **右键一个会话**：看它在做什么、**在新的一栏打开**、**设为协调者**、**资料** 等。
- 标题右边的按钮能把会话栏 **收起会话栏，只留头像**，鼠标移到头像上看名字和在做什么。窗口太窄时它也会自动收成标题下面的一排头像。

会话栏下面是「终端」：把你一台电脑上的一个文件夹交给项目里的 agent 跑命令。点 **+** 加一个，详见[终端](#help/terminals)。

## 交接卡片

会话之间互相派活、交还结果，不会以聊天气泡塞进你的对话里（那样看起来像在和你说话）。每一来一回折叠成一张小卡片，插在它开始的时间点：

- 第一行是「派给 [头像] xx」（派出去的活）或「[头像] xx 派来」（会话交给协调者的），后面是内容的第一行；
- 再后面是状态：**排队中**、**在做**、**交回了**（对方做完交回来了）、**做完了**、**没做成**，或者只是一条 **备注**；
- 对方交回结果后，下面多一行「↩ 结果的第一行」。

所以首页读起来是：你说一句 → 协调者派活 → 卡片一张张回来 → 它给你总结。点一张卡片，在右边一栏打开它们之间的完整往来（只读），能看到中间的过程。

![项目首页的交接卡片，右边一栏是一个会话的对话](shot:project-member-handoffs)

想看会话之间所有的往来，点项目标题右边的 **全部动态** 图标（一条波形线）：所有任务按卡片排开，只看不能发。

## 项目资料

点项目标题右边的文档图标打开 **项目资料**。最上面是项目名，下面一行小字写着它在哪个工作区、谁建的、谁能看（参与者可见 / 团队可见），再下面是目标。右上角有 **编辑**（改名字和目标）、**发任务**，和 **⋯** 里的项目设置（包括删除项目；删除只删项目本身，agent 和它们的对话都还在）。

下面三个标签页：

- **资料**
  - **项目说明**：项目里每个 agent 都该知道的事，比如仓库和分支、发版规则、怎么测试、注意事项。agent 每次干这个项目的活都会读到。
  - **项目记忆**：干活中定下来、大家都该记住的事，比如一个决定、一条约定、你的偏好。项目里的 agent 会自己往里记；你也可以点 **添加**，或点 **编辑** 删掉过时的、合并重复的。
  - **文件**：点 **上传** 或直接拖进来，20 MB 以内。项目里的 agent 能读到，也能自己往里放。
  - **资料链接**：仓库、设计稿、看板的地址。
- **会话**：谁在项目里、各自手上有几件活，以及项目能用哪些电脑（见下一节）。
- **对话**：项目里所有的对话，处理中、排队、失败、已完成各有多少。

![项目资料：项目说明和项目记忆](shot:project-notes)

## 项目能用的电脑

「会话」标签页下面有 **可以开 agent 的电脑**：工作区里每台电脑一行，右边一个开关。打开后，协调者就能在这台电脑上为项目开新的 agent（用哪些文件夹、最高什么权限，仍按那台电脑自己的设置）。只有能管理这个项目的人能拨开关。

协调者需要一台还没开放的电脑时，会在你和它的对话里弹一张卡片：「xx 想：让项目「…」在「…」上开 agent」，点 **同意** 或 **不同意**。

这和终端是两回事：终端是让 agent 在某个文件夹里跑命令，这里是让协调者能在那台电脑上开新 agent。

## 常见问题

**一个 agent 能同时在几个项目里吗？** 能。它的资料卡「所在项目」里列着它在的所有项目。

**我能绕过协调者直接给会话派活吗？** 能。在会话栏点它，在它那一栏里发就行，协调者不会收到。

**项目首页好像少了会话之间的对话？** 首页只放交接卡片和结果。点卡片看那一次的完整往来，或者点 **全部动态** 看所有的。

**怎么同时看好几个会话？** 拖一个会话到对话上，或右键 › **在新的一栏打开**，最多四栏，见[分屏](#help/panes)。
