# 项目和协调者

一件事要几个 agent 一起做，就建一个项目。

## 建项目

点边栏「项目」旁边的 **+**（或 **⌘N**）。写清楚目标，可以顺便放上需求文档、设计稿这些资料，协调者和成员一开始就知道要做什么。

## 协调者

每个项目有一个**协调者**：你告诉它要什么，它拆成小任务派给成员，盯进度、验收，最后告诉你结果。项目首页就是你和协调者的对话。

- 右边是成员栏：每个成员在做什么、谁在等你决定，最近活跃的在前。点一个成员，在旁边打开和它的对话。
- 成员之间派的活、交接，会以小卡片出现在对话里，点开看细节。
- 右键成员可以「设为协调者」。

## 项目资料

项目首页右上角的「项目资料」里：

- **资料**：项目说明（所有成员都该知道的事：仓库、分支、怎么测试）、项目记忆（干活中定下的约定，agent 会自己记）、文件、资料链接。
- **成员**：谁在项目里，以及协调者能在哪些电脑上开新的 agent。
- **对话**：项目里所有的对话和它们的状态。

## 并排看

拖一个成员到对话旁边，或右键「在新的一栏打开」，可以并排看几个 agent 干活，最多四栏。
