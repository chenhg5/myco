# 自动化

自动化让 agent 到点自己干活，或者在外部系统调用时开工。

## 建一个

「自动化」页 › 新建自动化。可以从模板开始（每日站会、周报、盯 CI……），也可以从空白开始：

1. **名字**。
2. **发给谁**：哪个 agent 来做。
3. **让它做什么**：一段话，和你平时在对话里说的一样。
4. **什么时候**：
   - **定时**：每天、工作日、每周几、每隔几小时，或者自定义 cron。时区用这台电脑的。
   - **Webhook**：CI、监控等外部系统调用一个地址时触发；外部传来的内容用 `{{payload}}` 放进任务里。保存后会给出地址、密钥和一条 curl 示例。

「上一次的任务还没做完，就跳过这次」默认是勾上的，免得活堆起来。

## 看运行记录

点开一个自动化，能看到每次运行：发出去了没有、哪个任务、结果如何。右上角「立即运行」手动跑一次，⋯ 里可以暂停、启用、删除。
