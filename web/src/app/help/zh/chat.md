# 和 agent 聊天

和 agent 聊天就像平时发消息：说一句要做什么，它去做，做的过程你都看得到。这一页讲怎么发消息和文件、它干活时怎么插话、怎么看它做了什么，以及对话里那些小工具。

下面的快捷键按 Mac 写；Windows 上把 ⌘ 换成 Ctrl、⌥ 换成 Alt。

## 打开一段对话

在边栏「会话」里点一个 agent，右边就是你和它的对话。项目里的 agent，在项目的会话栏点它。

新对话是空的，中间会问你想让它做什么，下面有几条例子（比如「带我看看这个项目：它是做什么的，怎么跑起来」「看下我还没提交的改动，有没有问题」）。点一条会填进输入框，改一改再发，不会直接发出去。不想看到例子，点「不再显示」。

## 发消息

- **回车**发送，**⇧回车**换行。
- 发出去的话会马上出现在对话末尾，稍淡一点，下面写着「发送中…」，到了工作区就变成正式的。
- 没发出去时，输入框上方出现一行淡红的「没发出去」，你写的字（和文件）都还在输入框里，点 **重试** 再发。
- 输入框是空的时候，按 **↑** 翻出之前发过的话，按 **↓** 往回翻。
- agent 回复时可以附一句「你下一步可能想说的」。这时输入框里会淡淡地显示这句话，按 **Tab** 填进去，改一改再发。
- 没发出的字会一直留着：切到别的对话再回来，或者重开 App，都还在。

## 发文件和图片

三种办法都行：

- 点输入框左下角的回形针选文件，或按 **⌘U**；
- 直接粘贴截图，或在访达里复制的文件；
- 把文件拖进输入框。

文件一加上就开始上传，在文字上方排成一个个小方块：图片只显示缩略图，别的文件显示图标和文件名。上传中有个小圈在转，传完才能发；失败的方块变红，鼠标移上去点 × 去掉。只发文件不写字也可以。

对话里收到的文件：

- **图片**点开看大图，← → 翻同一条消息里的其他图片，Esc 关掉。
- **文本文件**（Markdown、日志、代码……）点一下在右边打开，可以全屏、存到「下载」。同名文件再发一次会变成「第 2 版」，能看和上一版比改了什么。
- **其他文件**点一下存到「下载」文件夹。

## 它在干活的时候

它干活时，输入框右边的圆按钮变成 **■ 停止**，输入框写着「补充给 xx…」。这时你有三种选择：

- **回车 = 补充**：这句话会加进它正在做的这件事里，它在过程中就能看到，不用等它做完。适合「顺便把下载页也检查一下」这种。
- **⌘回车 = 排到下一条**：等它把这件做完再发。排着的消息在输入框上方，每条一行「排队中：……」，右边有 **编辑**（拿回输入框改）和 **撤回**。可以排好几条，按顺序一条条发出。
- **点 ■ 停止**：让它停下这一轮。

它停下或做完后，输入框回到「发给 xx…」，回车就是发一条新的。

![它干活时：补充的话进了这一轮，下一条在排队](shot:conversation-queue)

## 看它做了什么

在你的话和它的回复之间，是它这一轮的过程，像在 Claude Code、Codex 里看到的一样：

- 它边做边说的话直接显示出来。
- 思考、跑命令、读改文件，折叠成一行灰字，比如「想了一下、读了 1 个文件、跑了 1 条命令」。点一下展开看每一步，命令还能看到输出。
- **计划**卡片像待办清单一样一项项打勾，右上角写着「2 / 3 完成」。
- 它报告的进展排成一条小时间线，带时间。
- 正在做时，最下面有个走路的小蘑菇，写着它在干什么和用了多久。
- 做完后，回复下面会写这一轮的用时、token 和费用。

![一轮的过程：计划、折叠的步骤、进展和命令输出](shot:conversation-tool-trace)

觉得过程太多，打开 **设置 › 外观 › 对话里的过程**，选 **只看进度**：每一轮只显示它自己报告的进展和问你的问题，思考和命令都不显示。改回 **全部** 就又能看到。

## 它问你的问题

有时 agent 做到一半需要你拍板，会在对话里放一张问题卡片：「需要你决定」，下面是问题和几个选项。

- 点一个选项就是回答；
- 也可以在卡片底部的「或者直接说…」里写，或者直接在输入框里打字回车。

这时边栏里它的名字旁有个橙色小点，提醒你它在等你。回答后卡片会标出你选了哪个，它接着往下做。

![问题卡片：点一个选项，或者直接说](shot:ask-card)

## 好久没动静

一件事很久没有进展（一般是 10 分钟以上；它离线时马上），它的过程下面会多一行「N 分钟没有动静：可能做完了没收尾，也可能卡住了」，后面有四个按钮：

- **标记完成**：其实已经做完了，只是没收尾。点了就不再算它在干活。
- **再催一下**：发一句话问它这件事怎么样了。
- **停止**：不做了。
- **重发**：把这条消息重新发一遍。

对话标题右边也会出现「可能卡住」，点一下跳到那件事。

网络不好时不会乱报「卡住」：输入框上方会写「网络不太好」，说明这里的消息有一会儿没更新、agent 那边可能还在继续，App 正在自动重试，也可以点 **重试**。

你的消息下面那行小字也能帮你判断：「还没开始看」「排在后面」（它在忙前一件）、「稍后回复」（它把这件事先放一放，等别的事）、「对方离线，上线后再看」。

## 在对话里找

按 **⌘F**，或点对话右上角的放大镜，右上角浮出一个查找框：边打字边找，**回车**到上一处，**⇧回车**到下一处，**Esc** 关掉。找到的地方会标黄；更早的消息还没加载时，点「再往前找」。

想在所有对话里找，用边栏顶上的「搜索」（**⌘K**），见[快捷键](#help/shortcuts)。

## 置顶

常用的网址、文件或某条消息，可以置顶到对话标题下面那一排小标签里，点一下就打开：

- 鼠标移到一条消息上，点小图钉，就置顶这条消息（带文件的会问你置顶消息还是哪个文件）；
- 对话右上角 **⋯ › 置顶一个网址**，填网址和名字；
- 网页卡片右键 › **置顶到对话上方**。

标签可以拖动排序，右键能重命名、取消置顶。你和 agent 看到的是同一排，agent 也可以自己置顶。

## 文件和应用

对话右上角 **⋯ › 文件和应用**，右边打开一个面板，把这段对话里出现过的东西都列出来：agent 发布的应用和网页、所有图片、所有文件。上面的标签按类型筛选；每一项都有「在对话中查看」，点一下跳回那条消息。

![文件和应用：一段对话里的所有图片和文件](shot:chat-files)

## 导出、翻译和背景

- **导出**：**⋯ › 导出这段对话**。选格式（Markdown 给人看，JSON Lines 给程序用），可以勾「带上 agent 干活的过程」，文件存到「下载」文件夹。
- **翻译**：agent 回复的时间旁边有「翻译」，点一下翻成 App 的语言，再点「显示原文」回去。想自动翻译，到 **设置 › 翻译** 选一个翻译服务、填好密钥，再打开自动翻译。
- **聊天背景**：**⋯ › 聊天背景**，可以只给这个对话换，也可以设成所有对话的默认。有晨雾、薄荷、丁香、沙丘、点阵、方格六种，也可以选一张图片，用「淡化」调到字看得清。背景只存在这台电脑上。

## 删掉一条消息

鼠标移到消息上，点时间旁边的垃圾桶。它只从你这边消失，agent 和别人看到的不变；底部会出现「已删除 · 撤销」，几秒内可以反悔。

## 在对话之间切换

- **⌥↑ / ⌥↓**：按边栏的顺序，切到上一个 / 下一个对话。
- **⌃Tab**：按住 ⌃ 不放，按 Tab 挑一个 agent，松开就打开，像 ⌘Tab 切换程序一样。
- **⌘K**：搜索框空着时，第一组就是你最近打开过的对话，回车就回去。
- 对话左边的一列小刻度是你说过的每一轮，鼠标移上去看那一轮问了什么，点一下跳过去。
- 往上翻得远了，底部会出现一个向下的箭头（有新消息时显示「N 条新消息」），点一下回到底部。

## 专注模式

想只盯着一个对话时，点对话右上角的 ⋯ ›「专注模式」，或按 ⌘⇧F（Windows 上 Ctrl+Shift+F）。窗口变成全屏，边栏、顶栏、会话栏和旁边的栏都藏起来，只留这个对话在中间。这时 ⌃Tab、⌥↑ / ⌥↓ 照样能换到别的对话，换过去的对话也是一样的专注样子。按 Esc、再按一次 ⌘⇧F，或点右上角的「退出专注」回到原来的样子。

![专注模式：只留这个对话，旁边全藏起来](shot:focus-mode)
