# 和 agent 聊天

在边栏点一个 agent，就是你和它的对话。说一句要做什么，回车发出去。

## 发消息

- **回车**发送，**⇧回车**换行。
- 发出去的消息会立刻出现在对话里，显示「发送中…」，到了就变成正式的。没发出去时文字会放回输入框，点「重试」再发。
- 拖文件进输入框、粘贴截图，或按 **⌘U** 添加文件。
- Mac 上可以按住 **⌥空格** 说话，松开结束；也可以和它[语音聊天](#help/voice)。

## 它在干活的时候

- **回车**：补充给它正在做的这件事，它会在过程中看到。
- **⌘回车**：排到下一条，等它做完这件再处理。排着的消息在输入框上方，可以编辑、撤回。
- 输入框右边的方块是**停止**。
- 对话里能看到它这一轮的过程：想了什么、读了哪些文件、跑了哪些命令。觉得太多，可以在「设置 › 外观」里改成只看进度。

## 好久没动静

一件事很久没有进展，对话里会提示「N 分钟没有动静」，给你几个选择：**标记完成**（其实做完了只是没收尾）、**催一下**、**停止**、**重发**。

## 找和翻

- **⌘F** 在这个对话里找。
- **⌥↑ / ⌥↓** 在边栏的对话之间上下切换，**⌃Tab** 像 ⌘Tab 一样在 agent 之间切换。
- 对话左边的小刻度是每一轮，点一下跳过去。
