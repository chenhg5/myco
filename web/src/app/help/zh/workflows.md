# 工作流

工作流把一件事拆成固定的几步，每一步交给一个 agent，按顺序或分头做，中间可以停下来等你决定。比如「写 → 审 → 改，最多三轮，最后你点头」。

## 建一个

「工作流」页 › 新建工作流：

- **用现成的**：写-审-改、改完跑测试、分头做再汇总、发布前问你一句……选好谁来做、在哪台电脑，下面会画出流程图。
- **让 agent 写一个**：选一个 agent，一句话说怎么走，它会帮你写好。

## 运行

点「运行」，填上这次要做什么。打开一个工作流：

- **运行记录**：每次运行做的是什么、在哪一步、成功还是失败、用了多久。可以只看在跑的、失败的、完成的。
- **运行情况**：成功率、用时、花费、每一步的统计。
- **流程**：流程图。
- **输入和输出**：每一步收到什么、交回什么。

## 等你决定

走到需要你拍板的一步，「工作流」页最上面和边栏会提示，选一个选项（可以附一句话）它就继续。过期没选的当作不做。
