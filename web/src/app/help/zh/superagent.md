# superagent

superagent 是你在这个工作区的总管，名字固定叫 **Shroom**：你只要说要什么，它去找合适的 agent、开新的 agent、建项目、派活、盯进度。工作区里 agent 和项目多起来，不想一个个去点的时候，就配一个。

## 它能做什么

Shroom 本身是一个普通的 Claude Code 或 Codex 会话，只是多了替你管理工作区的权限。和它说一句话，它能：

- **派活、盯进度**：它找合适的 agent 去做，卡住了去催，做完回来告诉你。
- **开 agent、建项目**：在你允许的电脑上开新的 agent，建项目，把合适的 agent 拉进去。
- **看全局**：谁在忙、哪些任务卡住了、各个项目走到哪一步，问它就行。
- **要紧的事先问你**：删东西、停东西、改别人的权限这类事，它会先来问你，你点了「同意」它才做。

它总是以自己的名义说话，不会冒充你。每个人在每个工作区可以有自己的一个 superagent。

它的头像戴着一顶像素小皇冠，好认。它不在边栏「会话」的列表里，从工作区菜单或快捷键找它（见下面）。

## 配一个

1. 点左下角的工作区那一行，打开工作区菜单。
2. 点 **superagent**。还没配的时候，会弹出设置窗口。
3. 三种方式选一种（见下面），完成后会自动打开和它的对话。

![工作区菜单里的 superagent，旁边的数字是等你点头的事](shot:superagent-menu)

**新开 Shroom**：

1. 在 **开在哪台电脑** 里选一台在线的电脑。
2. 在 **用哪个 AI** 里选 Claude Code 或 Codex。
3. 点 **开一个 Shroom**。它在那台电脑的 `~/myco/shroom` 文件夹里干活。

如果你还没有在线、能开 agent 的电脑，先在[电脑](#help/computers)里连一台，或者用下面两种方式。

**用已有的**：在 **让哪个 agent 当 superagent** 里选一个你自己的 agent，点 **就用它**。

**一句话接入**：复制这句话，发给一个 Claude Code 或 Codex 会话：这台电脑上的、别的电脑上的、claude.ai 云端的都行。它加入后就是你的 superagent，窗口里写着「等它加入，加入后会自动打开和它的对话」。这句话 24 小时内有效、只能用一次，而且等同于凭据，只发给你自己的会话。

![配一个 superagent：新开、用已有的，或一句话接入](shot:superagent-setup)

## 和它聊天

配好之后，工作区菜单里的 **superagent** 就直接打开和它的对话。用法和别的 agent 一样：说要什么，回车发出去；它干活时可以补充、排队、停止，见[和 agent 聊天](#help/chat)。

不知道说什么，可以从这些开始：

- 「帮我看看今天哪些任务卡住了」
- 「开一个 Codex 在 Studio Mac 上，专门写测试，放进官网改版项目」
- 「建个项目做 iOS 客户端的发版，把 Release 和 Review 拉进去」
- 「每个项目现在到哪一步了？」

## 快捷小窗（Mac）

在 Mac 上，任何时候按 **⌘⇧空格**（App 不在前台也行），屏幕上会弹出一个小窗，直接把一句话交给 Shroom：

1. 按 **⌘⇧空格**。
2. 输入要做的事，**回车** 发出去（**⇧回车** 换行）。
3. 小窗收起，App 打开和 Shroom 的对话，在那里看它回。

小窗右上角的 **打开对话** 也能直接跳到完整对话。它有事等你点头时，输入框下面会多一行「Shroom 有 N 件事等你点头」，点 **去看** 打开对话处理。按 **Esc** 或点别处，小窗就收起。

小窗用的是 App 当前所在的工作区，不用另外选。还没配 superagent 时，它只有一句话和 **配一个**。

![⌘⇧空格 叫出的小窗](shot:superagent-quick)

Windows 和 Linux 版暂时没有这个小窗，从工作区菜单打开和它的对话就好。

## 它先问你的事

删项目、停 agent、改别人的权限、改自动化这类事，Shroom 不会自己动手，而是先来问你：

- 在它的对话里，输入框上方出现一张淡橙色的卡片：「Shroom 想：删除项目 old-site」，下面是它给的理由，和还剩多久有效。
- 右边点 **同意** 或 **不同意**。处理完卡片就消失，它会收到结果，接着往下做。
- 有几件在等，工作区菜单里 **superagent** 旁边就显示几；App 开着时还会弹系统通知。
- 没人处理的请求 24 小时后自动作废。

![等你点头的卡片：同意或不同意](shot:superagent-approval)

如果是要看或操作你某台电脑的屏幕，卡片上还会多一个 **只让它看**：只让它截屏看，不能用键盘和鼠标。同意后，同一个位置会显示它还能用多久，随时可以点 **收回**。

有些事它根本做不了，问你也不行，比如邀请成员、改成员角色、换别人的 superagent。

## 换一个，或者不要了

配好之后，工作区菜单里的 **superagent** 只会打开和它的对话。要换成别的 agent，或者不要 superagent 了，现在要在装了 myco 的电脑的终端里运行（只有你本人能设）：

```bash
myco superagent set --agent <名字>   # 换成你的另一个 agent
myco superagent unset                # 不要了：它变回普通 agent，在等你点头的事都作废
```

## 常见问题

**superagent 和普通 agent 有什么不一样？** 本质上一样，都是一个 AI 会话。区别是它能替你做 App 里能做的管理操作，要紧的会先问你。

**它能替我给别人发消息吗？** 不能冒充你。它发的每条消息都写着是它自己发的，审计里也记成「经 superagent」。

**Windows 上能用 superagent 吗？** 能。配置、聊天、点头都一样，只是没有 ⌘⇧空格 的小窗。
