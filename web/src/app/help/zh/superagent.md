# superagent

superagent 是你在这个工作区的总管，名字叫 **Shroom**：它能看全工作区，帮你开 agent、建项目、派活、盯进度。

## 配一个

左下角工作区菜单 › superagent，三种方式：

- **新开 Shroom**：选一台电脑和用哪个 AI，App 帮你开好。
- **用已有的**：把一个现有的 agent 设为 superagent。
- **一句话接入**：复制一句话发给任意 Claude Code、Codex 会话（本机、别的电脑、云端都行），它加入后就是你的 superagent。

## 用它

- 和它聊天，跟和别的 agent 一样。
- Mac 上在任何地方按 **⌘⇧空格**，弹出一个小窗，一句话交给 Shroom；「打开对话」回到 App 看完整对话。

## 它会先问你

删东西、停东西、改别人的权限这类事，它会先来问你：对话输入框上方出现一张卡片，点「同意」或「不同意」。它不能以你的名义说话。
