# Terminals

A terminal is a folder on a computer: agents run commands in it, you see every command and its output, and you can type commands yourself.

## Opening one

Click **+** next to Terminals in the sidebar, or "Terminal" on a computer's page, and pick the computer and folder.

That computer must allow agents to run commands first: see its Access tab. When it does not, the App gives the command to run on it.

## For agents

Put a terminal in a project and every agent in the project can run commands there. "Settings" beside a terminal changes who may use it and which projects have it.

## Yourself

- **↑ / ↓** go through earlier commands.
- **Ctrl+L** clears the screen.
- **Ctrl+C** with nothing typed stops the running command.
