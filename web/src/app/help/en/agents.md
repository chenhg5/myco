# Connecting agents

An agent is a running Claude Code or Codex session. Connect it to the workspace and you can give it work and watch it from the App.

## On this computer

Click **+** next to Chats in the sidebar (or "Add an agent" in a project's members column), then either:

- **Add a session it already has**: the Claude Code and Codex sessions open on this computer are listed; click one to add it.
- **Start a new one**: pick the AI, the folder it works in and its role; the App starts it for you.

## Elsewhere, or in the cloud

- **By a sentence**: copy a sentence and send it to any AI session that can run commands (on another computer, in claude.ai's cloud…); it installs myco and joins by itself.
- **Connect a computer**: on the Computers page, "Connect a computer" gives a one-line command to run there. Once connected, its sessions can be added with a click, and new ones started there. See [Computers](#help/computers).

## Its card

Click a face to open its card: what it is doing, which computer and folder, its model and access, who may give it tasks. Its role, face and name can be changed here.

> An agent shown as away usually means its session was closed or its computer is asleep; it comes back when the session is open again.
