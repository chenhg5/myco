# Keyboard shortcuts

Almost everything you do often in the App has a key, and a few of them save a lot of clicking. The full list is under **Settings › Shortcuts**, which **⌘/** (Ctrl+/ on Windows) opens at any time; below it is grouped the same way, with a column each for the Mac and Windows keys.

![Settings › Shortcuts: every key the App listens for](shot:settings-shortcuts)

On a Mac, ⌘ is Command, ⌥ Option, ⌃ Control and ⇧ Shift. On Windows and Linux the keys are Ctrl, Alt and Shift. Shortcuts can't be changed yet.

## Anywhere

These work anywhere in the App.

| What | Mac | Windows |
| --- | --- | --- |
| Search: chats, members, projects and messages | ⌘K | Ctrl+K |
| Back / forward | ⌘[ / ⌘] | Ctrl+[ / Ctrl+] |
| Switch agents (as ⌘Tab does) | ⌃Tab / ⌥Tab | Ctrl+Tab / Ctrl+\` |
| Previous / next conversation | ⌥↑ / ⌥↓ | Alt+↑ / Alt+↓ |
| Focus mode (press again, or Esc, to leave) | ⌘⇧F | Ctrl+Shift+F |
| Switch to workspace 1–9 | ⌘1…9 | Ctrl+1…9 |
| New project | ⌘N | Ctrl+N |
| Show / hide the sidebar | ⌘\\ | Ctrl+\\ |
| Open Settings | ⌘, | Ctrl+, |
| Keyboard shortcuts | ⌘/ | Ctrl+/ |
| Refresh | ⌘R | Ctrl+R |
| Larger / smaller text | ⌘= / ⌘- | Ctrl+= / Ctrl+- |
| Standard text size | ⌘0 | Ctrl+0 |
| Switch light / dark | ⌘⇧L | Ctrl+Shift+L |
| Close a dialog, menu or panel | Esc | Esc |

A few notes:

- **Search** brings up a box near the top of the screen that finds members, projects and computers in every workspace, and messages in your own chats. ↑↓ to pick, Enter to open. With nothing typed, the first group is the chats you opened recently, so ⌘K then Enter takes you back to the last one.
- **Back / forward** go to where you were, as ‹ › at the top do; a mouse's side buttons work too.
- **Switch agents**: keep holding ⌃, press Tab or ← → to pick (⇧Tab goes back), let go to open. On a Mac ⌃← → switch desktops, so hold ⌥ to use the arrows. In a browser, use \` instead of Tab.
- **Previous / next conversation** follow the sidebar's order, projects and chats alike.
- **Switch workspace** follows the order of the workspace list at the bottom left; each workspace in that menu shows its key.

![⌃Tab switches agents: hold ⌃, press Tab to pick, let go to open](shot:agent-switcher)

## In a chat

| What | Mac | Windows |
| --- | --- | --- |
| Find in this chat | ⌘F | Ctrl+F |
| Previous / next match (in the chat's find box) | Enter / ⇧Enter | Enter / Shift+Enter |
| Add files | ⌘U | Ctrl+U |

You can also paste files or drop them on the box. With split panes, ⌘F finds in the pane you clicked last.

## Writing a message

| What | Mac | Windows |
| --- | --- | --- |
| Send | Enter | Enter |
| New line | ⇧Enter | Shift+Enter |
| Queue it after the current task | ⌘Enter | Ctrl+Enter |
| Go through what you sent before (from an empty box) | ↑ / ↓ | ↑ / ↓ |
| Use the agent's suggested reply | Tab | Tab |
| Hold to talk, let go to stop (caret in the box) | ⌥Space / ⌃M | Ctrl+M |

- **Queue it**: for when the agent is at work. Enter alone adds your words to what it is doing; ⌘Enter waits until it has finished. See [Chatting with agents](#help/chat).
- **Hold to talk**: on Windows Alt+Space opens the window menu, hence Ctrl+M. See [Voice](#help/voice).

## In a terminal

| What | Mac | Windows |
| --- | --- | --- |
| Previous / next command | ↑ / ↓ | ↑ / ↓ |
| Clear the screen | ⌃L | Ctrl+L |
| Stop the running command (nothing typed) | ⌃C | Ctrl+C |

In a terminal it is Control on a Mac too, not Command. For more on terminals, see [Terminals](#help/terminals).

## Search and Settings

| What | Mac | Windows |
| --- | --- | --- |
| Move through the results | ↑ / ↓ | ↑ / ↓ |
| Open the one picked | Enter | Enter |
| Search Settings (with Settings open) | ⌘F | Ctrl+F |

Searching Settings works in Chinese or English, such as "字号" or "proxy"; Esc first clears the search box, and a second Esc closes Settings.

![⌘K finds members, projects, computers and messages](shot:search-anything)

## Mac only

- **⌘⇧Space**: anywhere, even with the App in the background, brings up Shroom's panel to hand your superagent something in one line. See [The superagent](#help/superagent).
- The menu bar at the top of the screen lists most of these keys too (New Project, Search, the sidebar, text size, light and dark…), in case you forget one.
