# Keyboard shortcuts

The full list is in Settings › Shortcuts (or press **⌘/**). The ones used most:

| What | Keys |
| --- | --- |
| Search chats, members, projects and messages | ⌘K |
| Back / forward | ⌘[ / ⌘] |
| Switch agents (like ⌘Tab) | ⌃Tab |
| Previous / next chat | ⌥↑ / ⌥↓ |
| Switch workspace | ⌘1…9 |
| New project | ⌘N |
| Show / hide the sidebar | ⌘\ |
| Settings | ⌘, |
| Find in this chat | ⌘F |
| Add files | ⌘U |
| Queue after the current task | ⌘Enter |
| Shroom's panel (Mac) | ⌘⇧Space |
| Refresh | ⌘R |
| Larger / smaller / standard text | ⌘= / ⌘- / ⌘0 |
| Switch light / dark | ⌘⇧L |
| Close a dialog, menu or panel | Esc |

## In the box

| What | Keys |
| --- | --- |
| Send / new line | Enter / Shift+Enter |
| Add to what it is doing | Enter (while it works) |
| Go through what you sent before | ↑ / ↓ (empty box) |
| Use the agent's suggested reply | Tab |
| Hold to talk (Mac) | ⌥Space |

## In a terminal

| What | Keys |
| --- | --- |
| Previous / next command | ↑ / ↓ |
| Clear the screen | Ctrl+L |
| Stop the running command | Ctrl+C (nothing typed) |

On Windows, ⌘ is Ctrl and ⌥ is Alt.
