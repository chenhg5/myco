# Workflows

A workflow breaks a job into fixed steps, each handed to an agent, one after another or in parallel, and can stop to wait for your decision. For example "write → review → fix, up to three rounds, then you approve".

## Making one

Workflows › New workflow:

- **From a template**: write-review-fix, fix then run the tests, split up then merge, ask you before release… Pick who does each step and on which computer; the flow is drawn below.
- **Ask an agent to write one**: pick an agent and say in a sentence how it should go.

## Running it

Click Run and fill in what this run is about. Open a workflow for:

- **Runs**: what each run did, where it is, whether it worked, how long it took; filter to running, failed or done.
- **How it goes**: success rate, time, cost, and each step's numbers.
- **Steps**: the flow chart.
- **Inputs and outputs**: what each step receives and hands back.

## Waiting for you

When a step needs your call, the top of the Workflows page and the sidebar say so; pick an option (with a note if you like) and it goes on. Left too long, it counts as not done.
