# The superagent

Your superagent, **Shroom**, runs this workspace for you: it sees everything, starts agents, makes projects, hands out work and keeps track.

## Setting one up

Workspace menu (bottom left) › superagent, three ways:

- **New Shroom**: pick a computer and an AI; the App starts it.
- **Use one**: make an agent you already have the superagent.
- **By a sentence**: copy a sentence to any Claude Code or Codex session (here, on another computer or in the cloud); once it joins, it is your superagent.

## Using it

- Chat with it like any agent.
- On a Mac, press **⌘⇧Space** anywhere for a small panel to hand Shroom something in one line; "Open chat" takes you to the full chat in the App.

## It asks you first

Deleting, stopping or changing someone's access, it asks you first: a card above the chat's box, with Approve and Decline. It never speaks as you.
